# LilacAnime 업데이트 지속 패치 매니저 — 안전성 기반 시제품

**목표:** 기존 LilacAnime의 공식 업데이트를 유지하면서 Patch 01(방영표·출처 상태)과 Patch 02(수동 ChatGPT 자막 번역)가 화면 안에 유지되도록, 업데이트 이후 호환성을 판단하고 안전할 때 재적용한다. 다른 통합판/오버레이를 최종 제품으로 삼지 않는다.

## 현재 구현

- `core.cjs`: 정확한 버전과 2개 이상의 대상 파일 SHA-256, 삽입 지점 및 중복 적용 검사. 예기치 않은 변경은 `incompatible`로 중단
- `staging.cjs`: OS 임시 폴더에 **새로 만든 합성 테스트 트리**만 허용. 원본 트리 대신 새 임시 사본에 테스트 표시를 삽입. 일반 파일 경로, 심볼릭 링크, 알 수 없는 작업을 차단
- `cli.cjs`: `--help`, `--demo`만 제공. 실제 설치본 패치 명령 없음
- `test/manager.test.cjs`: 업데이트 버전 변경, 파일 해시 불일치, 비침범 삽입, 누락 마커, 경로 이탈, 링크, 잘못된 패치 동작, 모호한 앵커 검증

## 테스트

```powershell
node --test patch-manager/test/manager.test.cjs
node patch-manager/cli.cjs --help
```

`node patch-manager/cli.cjs --demo`는 사용자가 실행할 때만 별도의 합성 임시 폴더 두 개를 새로 생성한다. 생성한 임시 폴더는 사용자 확인 없이 자동 제거하지 않는다.

## 아직 구현하지 않은 내용

- 공식 v0.5.14 실제 소스에 Patch 01·02를 적용하는 버전별 어댑터
- 원본 `app.asar`와 패치 리소스의 검증된 안전 백업·적용·복구
- 원본 업데이터의 완료 신호 감지, 파일 잠금 처리, 코드 서명 및 업데이트 경합 해소
- 업데이트 후 자동 재적용 및 사용자 환경에서의 영구 유지
- Windows 실제 UI, 실제 영상 출처, ChatGPT 왕복 검증

**지금은 안전 판단과 합성 사본 적용을 검증한 1단계야. 업데이트 뒤에도 패치 01·02가 실제로 유지된다는 증거는 아직 없다.**

## 안전 경계

`D:\LilacAnime`, `%APPDATA%\lilacanime-desktop`, `%LOCALAPPDATA%\lilacanime-desktop-updater`를 읽거나 수정하지 않는다. 실제 설치·제거·업데이트 후킹·NSIS·프로세스 강제 종료·Computer Use·원격 디버깅을 수행하지 않는다.

원본에는 공식 외부 확장 API가 없으므로 최종적으로 원본 화면 안에 패치를 유지시키려면 원본 리소스 수정이 필요할 수 있다. 이는 사용자가 기존에 설정한 원본 무수정 조건과 충돌하므로, **실제 설치본 수정 기능을 개발·작동시키기 전 별도의 명시적인 승인과 충분한 격리 검증이 필요하다.** 검증하지 않은 신규 버전에서는 재적용을 멈추고 공식 업데이트를 방해하지 않는다.
