# Lilac Dino Patch 0.1.0 Beta 1

Windows x64용 비공식 LilacAnime Desktop 소스 패치 관리자입니다. 공식 애플리케이션을 대체하지 않고, 호환되는 공식 소스 폴더에서 기존 홈·상세·회차·재생 경로를 유지하며 디노 패치 기능을 관리합니다.

**공식 원본:** https://github.com/whispelyn-byte/LilacAnime-desktop

## 포함된 개선

- 수동으로 디노 패치를 해제한 동일한 공식 소스에 대해 자동 재적용을 억제하고, 사용자 해제 의도를 보존합니다.
- 패치 관리자 엔진의 적용·해제·원본 복원 및 중복 백업 방지 처리를 보강했습니다.
- 통합 검색 선택 상태를 Dino 전용 키에 저장하여 공식 앱의 공급원 설정 키와 충돌하지 않도록 했습니다.
- 복구 근거가 있는 이전 공급원 값만 안전하게 이전합니다. 근거가 없거나 손상된 legacy 설정을 임의로 추측하거나 덮어쓰지 않습니다.

## 사용 대상

- Windows x64
- 공식 LilacAnime Desktop의 **소스 트리**가 필요합니다. 일반 설치 프로그램이 제공하는 패키지 파일만으로는 동작하지 않을 수 있습니다.
- ZIP을 풀어 나오는 DinoPatchManager 폴더 전체를 공식 소스 루트에 배치하고, 관리자 EXE를 실행합니다.
- 관리자는 기존 공식 파일 구조·지문·호환성을 검사한 뒤 지원되는 원본에만 패치를 적용합니다. 패치 해제는 수정했던 공식 소스 파일의 복원이며 전체 사용자 프로필의 초기화·복원이 아닙니다.

## 검증 범위와 알려진 제한

- 사용자 보고에 따르면 기존 A/B 소스의 Python 관리자 68/68, Node UI 21/21, 설정 보존 15/15, legacy 공식 계약 6/6, Patch 03 계약 13/13, Companion 22/22를 통과했습니다.
- 하나의 검증 환경에서 전체 npm 테스트 401개 중 397 통과, 0 실패, 4개 건너뜀(v0.5.14 fixture 필요)이 기록됐습니다. 다른 fixture 없는 환경에서는 384 통과, 17개 건너뜀으로 별도 기록됐습니다.
- A 기반 **별도 실험 패키지**로 v0.5.55의 GUI 해제·복원·재시작을 확인했습니다. 최종 B 포함 패키지의 동일 GUI 검증을 마쳤다는 의미는 아닙니다.
- 정확한 Git 객체 기반 공식 v0.5.58 fixture에서 엔진 적용·해제·명시적 재적용·재해제와 공식 파일 170/170 원상 복원을 검증했습니다.
- **GUI에서 사용자가 클릭하는 수동 재적용 버튼은 이번 배포 소스에 포함되지 않습니다.** 별도 실험 코드의 GUI 검증은 INTERRUPTED입니다.
- 이전 값의 복구 근거가 없는 contentSource='integrated' 상태는 자동 변경하지 않으므로, 필요하면 공식 앱 설정 화면에서 사용자가 지원되는 공급원을 직접 선택해야 합니다.
- 실제 사용자 프로필 및 모든 외부 공급원의 현행 스트림·재생 흐름은 이 후보에서 최종 검증되지 않았습니다. 기능적 융합 전체 판정은 PARTIAL입니다.
- 모든 공식 최신 버전에 자동 호환되거나 모든 외부 공급원을 지속적으로 사용할 수 있다고 보장하지 않습니다.

이 프로젝트는 **LilacAnime 공식 제작진의 승인·제휴 제품이라는 의미가 아닙니다.** 코드·에셋·의존성·외부 콘텐츠의 라이선스와 각 사용 조건을 준수해야 합니다. 영상·자막 콘텐츠 파일은 릴리즈 패키지에 포함하지 않습니다.
