- A: GUI 수동 해제 이후 동일 원본에서 자동 재적용을 억제하고 원본 복원·백업·관리자 상태 처리를 보강했습니다.

- 미커밋 수동 재적용 GUI 실험본은 **이번 소스 커밋에 포함되지 않습니다.**

## 알려진 제한

- 전체 기능적 융합 판정은 **PARTIAL**입니다.
- GUI에서 사용자가 누르는 수동 재적용 버튼은 이 후보에 없습니다.
- 복구 기록이 없는 옛 `contentSource='integrated'` 값은 사용자의 공식 공급원 선택 없이 자동 변경하지 않습니다. 패치 해제는 원본 소스 파일 복원이며 전체 사용자 프로필 복원이 아닙니다.
- 공식 v0.5.58의 실제 전체 main/preload/renderer 실행 및 외부 공급원·실제 스트림의 현행 연결 상태는 이 후보에 대해 최종 검증되지 않았습니다.
- 패치 대상은 공식 소스 구조와 지문 검사가 통과하는 경우에 한정됩니다. 공식 저장소의 모든 최신 버전을 자동 지원하지 않습니다.

## 게시 전 필수 조건

1. **배포 권리 근거**: 사용자는 원본 수정·재배포 허가를 확보했다고 말했습니다. 허가 주체, 배포 범위, 코드·에셋, 실행 파일·GitHub 업로드 범위와 요구 표시를 실제 기록으로 확인하고 저장소의 `docs/RIGHTS_REVIEW.md`를 갱신해야 합니다. 이 대화에서 허가 문서 자체를 확인하지는 않았습니다.
2. **의존성·콘텐츠 권리**: FFmpeg, JASSUB, 그 밖의 내장 코드·폰트 고지 및 공급원 이용 조건의 공개 배포 차단 항목을 확인하거나 해당 항목을 배포본에서 제외해야 합니다. 영상·자막 파일을 ZIP에 포함하지 않습니다.
3. **관리자 전용 빌드**: 저장소 루트 `.github/workflows/build.yml`은 원본 LilacAnime 앱용이며 디노 관리자 배포로 사용하지 않습니다. 독립 관리자 빌드의 입력 커밋과 산출물이 일치함을 확인해야 합니다.
4. **배포 게이트**: `LILAC_RELEASE_RIGHTS_APPROVED`를 편의상 설정하거나 검사를 우회하지 않습니다. 승인 완료를 확인한 경우에만 지정된 절차로 진행합니다.
5. **최종 아티팩트 정보**: 실제 Windows x64 ZIP 파일명·크기·SHA-256, 빌드 커밋, 설치 안내, 필수 고지를 확보합니다. 기존 A35 파일을 덮어쓰지 않습니다.

승인 및 파일 확인 후에만 실제 태그와 비공개 프리릴리즈를 게시합니다. 공개 게시/배포가 허용되는지 별도로 구별합니다.
