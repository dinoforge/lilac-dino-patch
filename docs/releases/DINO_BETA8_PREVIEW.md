# DinoPatch Beta 8 PREVIEW — 개발 검증용

이 패키지는 **정식 Beta 8 릴리스가 아닙니다.** Windows Rust GUI의 실제 빌드, 종료/재시작, 패치 적용·해제·복구 및 기존 사용자 데이터 보존 검사를 위한 후보입니다.

## 패키지 구성

- `LilacAnime-DinoPatch-Rust.exe`: 기존 LilacAnime 설치본에 패치를 적용하는 독립 Rust 관리자 GUI
- `package-info.json`: 빌드 Git 커밋, 실행 파일 및 내장 패치 manifest 해시
- `SHA256SUMS.txt`: 실행 파일 SHA-256
- 이 문서

공식 LilacAnime 프로그램 자체, 공식 `app.asar`, 저작권 보호 영상 및 개인 설정/DB는 포함하지 않습니다.

## 포함 기능 (소스 코드 수준)

- 기존 원본 지문 검증, 백업 SHA-256 확인, 패치 전후 상태 검사, 해제 시 복구 기록
- SQLite 작품 인덱스 v3: 5개 공급원, 연결 이력, 한국어 제목 변경 기록, 연결 사전 검사
- 저장된 작품 제목 검색, 공급원 수동 연결·분리, 상태 및 무결성 표시
- 방영 작품만 제한적으로 최신 회차 확인, 중복 더빙/특별편 제외, 일시 중지/재개
- 다른 공급원 재생 전 동일 작품·회차 검증 및 실패 시 재시도

## 실제 사용 전 주의

1. 원본 설치본을 그대로 테스트하지 말고 안전한 **복사본**과 별도 테스트 프로필을 사용하세요.
2. 설치본 `LilacAnime.exe`와 `resources/app.asar`가 모두 유효한 일반 파일이어야 합니다.
3. 정식 LilacAnime의 한국어 제목, 사용자 프로필, 기존 패치 백업은 삭제하거나 덮어쓰지 마세요.
4. 패치 후 기존 앱을 실행하고 통합 검색, 공급원 편집, 회차 갱신, 재생 전환을 확인하세요.
5. 해제·복원 시 원본 해시가 일치하는지 확인하세요. 미완료 작업 기록이 남으면 강제 덮어쓰지 말고 복구 검사를 사용하세요.

## Beta 8 정식 전환 필수 조건

- 로컬 Node 사전 점검 및 Rust `cargo test` 통과
- Windows GUI/PE 서브시스템 2, 시작 및 종료 테스트 통과
- 적용·해제·복구 시 전원 중단/해시 충돌 등 오류 상황을 안전하게 차단
- SQLite v2→v3 업그레이드, 오래된 제목·수동 연결·회차 상태 보존 검증
- 5개 공급원의 실제 API 응답 및 여러 공식 원본 버전 호환성 시험
- 패키지 해시 대조, 수동 설치 및 백업 복구 시나리오 확인

이 후보는 `workflow_dispatch`로만 빌드합니다. GitHub Actions는 작업 브랜치 푸시로 실행되지 않습니다.
