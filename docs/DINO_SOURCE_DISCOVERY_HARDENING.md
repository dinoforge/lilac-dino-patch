# Beta 8: 공급원 연결이 항상 1/5로 보이는 문제

## 확인된 원인

일부 공식 공급원(특히 Animenosub)의 검색 목록은 작품의 방영 연도 `year`를
빈 문자열로 반환합니다. 반면 DinoPatch는 교차 공급원의 외부 작품 ID가
없으면 **정확한 제목 별칭, 동일 방영 연도, 시즌·형식 호환성**을 요구합니다.
따라서 다른 공급원 검색이 성공해도 목록 정보에 연도가 없으면
동일 작품의 링크가 1개로 남을 수 있습니다.

이것은 같은 작품이 반드시 5개 공급원 모두에 있다는 뜻이 아닙니다.
실제로 공급원이 작품을 제공하지 않거나 제목/시즌 정보가 불충분한
경우에는 1/5가 정상일 수도 있습니다.

## 소스 개선

- 검색 결과 중 **공식 제목/별칭이 정확히 일치하는 후보**만 정밀 검사합니다.
- 작품 상세 페이지의 공식 `providerDetail`에서 누락된 연도 등의 정보를
  가져와 기존 보수적인 `identityMatch` 검사를 다시 적용합니다.
- 상세 조회는 전경 4개 후보, 백그라운드 1개 후보로 제한하고
  세션 메모리에서 10분 동안 결과를 재사용합니다.
- 연도·시즌이 충돌하면 제목이 같아도 자동 연결하지 않습니다.
- 일치할 수 있으나 필요한 메타데이터가 없는 후보는
  `작품 확인 필요`라고 표시합니다.
- `다른 공급원 다시 찾기`를 누르면 이전 SQLite의 fresh/missing 기록을
  이유로 재검색을 건너뛰지 않습니다.
- 기존 SQLite, 로컬 제목, 수동 연결·분리 기록, 설치본 백업은
  삭제하거나 초기화하지 않습니다.

## 검증 상태

새로 추가한 테스트용 화면 검증 4개가 통과했습니다. 공식 v0.5.65
실사용 설치본에서 전체 작품 자동 연결 수까지 검증된 것은 아닙니다.
공급원별 실제 응답과 검색 가능 여부에 따라 연결 수는 달라집니다.

이 문서와 변경 소스만으로 사용자의 기존 EXE가 업데이트되는 것은
아닙니다. Windows 패키지 재빌드 전에 추가 Node/Rust/Windows 검증이
필요합니다. GitHub Actions CI는 이 브랜치를 위해 실행하지 않았습니다.
