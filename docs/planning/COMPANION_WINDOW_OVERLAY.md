# LilacAnime Companion — Windows 무수정 도킹 오버레이 구현 계획

상태: **1단계 지오메트리 코드만 작성됨. 실제 OS 창 탐색, 추적 UI, Windows 실행은 미구현/미검증.**
기준: `codex/runtime-attach-unmodified-feasibility` / `c8b180bff0d36d7b523d0ae2f74b34d42a0ee994`.
새 작업 브랜치: `codex/companion-window-overlay`.

## 사용자 요구

원본 LilacAnime는 공식 업데이트를 계속 사용한다. Companion은 별도 프로세스이되 원본 창 바로 옆에 자연스럽게 붙는 작은 패널이어야 한다. **원본 renderer 내부 삽입**이라 주장하면 안 된다. 원본 제작자에게 Issue/PR을 제출할 필요 없이 개인용 Companion으로 진행한다. 기존에 검증한 방영 일정의 색상·글꼴·칩·카드 스타일을 참고하되 오버레이에서는 해당 스타일을 명시적으로 구현한다. 다른 앱을 가리거나 원본 버튼을 침범하면 안 된다.

## 우선 구현 순서

1. `companion/overlay/geometry.cjs`의 비침범 배치 함수와 테스트가 시작점이다. Win32 화면 좌표와 Electron DIP 좌표를 혼용하지 않는다.
2. 사용자가 명시적으로 'LilacAnime 창 따라가기'를 누르면 **창 제목, 프로세스명, HWND/PID, 위치·최소화·전면 여부**만 Windows 창 API로 관찰한다. 원본 프로세스 메모리, 쿠키, 세션, 사용자 설정, 창 내용/접근성 텍스트는 읽지 않는다. PID는 재사용될 수 있으므로 동일성은 매 관찰 때 재검증한다. 다중 LilacAnime 인스턴스는 임의 연결하지 않고 사용자에게 선택을 요구한다.
3. 원본 창과 겹치지 않는 좌/우 바깥쪽에 338px가량의 도킹 패널을 배치한다. 충분한 공간이 없으면 **원본을 가리지 않는 수동 위치 모드**로 전환한다. 게임/전체화면/다른 앱이 전면에 있으면 항상 위로 떠서 방해하지 않는다. 원본 최소화·종료·변경 시 안전하게 도킹을 해제하거나 숨김 처리하고 트레이/작업표시줄에서 회복 가능해야 한다.
4. 패널에는 월~일 일정, 현재 분기, 클릭 시 정확 회차의 **합성 5개 출처 상태**, 수동 ChatGPT 번역 보조로 이동할 수 있는 버튼만 제공한다. 기존 Companion의 합성 데이터와 프롬프트/자막 로직을 재사용한다. **실제 방영표나 실시간 재생 가능으로 표시하지 않는다.** 원본 재생 제어·현재 회차 인식·자막 자동 적용은 지원되지 않는다.
5. 스타일: `src/ott.css`, `src/styles.css`, 원본 스타일 검증 `RUNTIME_ATTACH_NATIVE_STYLE.md`의 색상/글꼴/칩 디자인을 기준으로 한다. 다른 프로그램의 크고 화려한 카드형 앱처럼 보이지 않도록 한다. 도킹된 작은 창의 콘텐츠는 키보드 접근 및 좁은 화면 스크롤을 지원한다.
6. 실행 전 명시적 동의, 언제든 '따라가기 해제' 버튼과 독립 종료가 있어야 한다. Windows 상태 확인 실패·PowerShell 실행 정책 제한·DPI 불일치 시 무리하게 따라붙지 말고 수동 모드로 돌아온다. OS 명령을 사용할 때는 문자열 삽입/쉘 확장 금지, 로컬 고정 스크립트만 실행하고 출력을 엄격히 검증한다.
7. 안전성 테스트: 앱 비접근 상태, 원본 존재, 최소화, 종료, 다른 앱 전면, DPI 100%/150%, 멀티 모니터, 음수 가상 화면 좌표, 화면 가장자리, 고해상도/소형 화면, 다중 원본 창, 이름이 유사한 타 앱, 창 이동/최대화, Companion 종료, 사용자 데이터 경로 쓰기 0회, 창 권한 오류 모두 확인한다.
8. 실제 OS 창 연동을 검증할 때는 **먼저 별도 합성 대상 창**으로 추적 기능을 시험한다. 실사용 LilacAnime 실행본의 창 메타데이터 관찰은 사용자가 명시적으로 승인하기 전 수행하지 않는다. 기존 중단된 Computer Use 감사 재개 금지. 설치 없이 Electron 개발 실행만 사용한다.
9. 문서 `docs/verification/COMPANION_OVERLAY_WINDOWS.md`에 동작 캡처, UI 중첩 여부, DPI 결과, 원본 해시/사용자 데이터 무변경, 한계와 실패 동작을 기록한다. 보고 시 합성 데이터/실제 데이터, 별도 overlay/원본 내부 UI를 반드시 구분한다.

## 절대 보호

- `D:\LilacAnime`, `%APPDATA%\lilacanime-desktop`, `%LOCALAPPDATA%\lilacanime-desktop-updater` 파일 내용과 경로는 접근/수정하지 않는다. Windows 창 관리 API를 통한 공개 창 위치 외 원본 내부 정보를 탐색하지 않는다.
- 기존 중단 감사 worktree, 31개 미추적 캡처, 5개 로그와 사용자 기록은 손대지 않는다.
- 원본 `app.asar` 변경, NSIS 설치/제거, 원본 재실행, DLL 주입, CDP 원격 포트, 자동화 입력, 원본 커맨드 실행을 금지한다.
- 다음 화 자동재생, LinkAni, ChatGPT 비공식 세션 사용을 추가하지 않는다.
- 새 브랜치에만 개발·커밋하고 `main`, 기존 패치·Companion 브랜치, upstream은 보존한다.
