# LilacAnime 독립형 Companion/애드온 구조 타당성 검토

검토일: 2026-10-10
작업 기준: `codex/integration-01-02`의 `4610a45f52e9a076b67a6774bcf3887dc390e485`
검토 범위: 연결된 GitHub 소스의 정적 확인. 사용자 Windows PC의 실제 설치본, 외부 공급원 서비스, 실시간 재생은 검사하지 않았다.

## 확정된 사용자 의도

- 원본 LilacAnime는 평소처럼 공식 업데이트를 계속 받는다.
- 원본 실행 파일, `app.asar`, 설치/업데이트 경로, 사용자 데이터, 설정·시청 기록을 덮어쓰거나 변형하지 않는다.
- 우리 패치 01(분기·요일별 방영표/다섯 출처 확인)과 패치 02(영어·일본어 사용자 프롬프트를 쓴 ChatGPT 수동 번역)를 **부가 프로그램처럼** 쓴다.
- 별도 NSIS 설치를 자동으로 진행하지 않는다. 우선 설치 없는 개발 실행·테스트만 허용한다.
- 기존 기능을 새 앱으로 교체하지 않으며 `main`과 원본 저장소를 수정하지 않는다.

## 안전한 구성 권고 — 독립형 Sidecar Companion

1. **독립 실행:** 별도 앱 ID·앱 이름·프로필 디렉터리, 원본 앱 및 프로필 경로에 대한 쓰기 금지. 시작은 설치 없는 개발용 실행으로 한다. NSIS·원본 패키지 변경·인젝션 없음.
2. **패치 01 분리:** 현재 날짜를 기준으로 분기/요일표 계산하는 순수 도메인 코드와 작품 식별·출처/회차 상태 로직을 Companion에서 재사용한다. 원본 홈 화면 대신 Companion 자체 창에서 일정을 보여 준다. 다섯 출처의 실제 확인은 별도 어댑터 경계로 두고 네트워크/이용 권한/오류를 분리한다. 애드온이 원본의 재생 버튼을 원격 제어할 수 있다고 주장하지 않는다.
3. **패치 02 분리:** 사용자 제공 프롬프트 원본 바이트 및 언어 선택·VTT 검증 로직을 재사용한다. **사용자가 선택한 로컬 자막 파일**을 번역 보조하고 검증 완료된 새 VTT/SRT를 별도로 내보낸다. 원본 앱의 지원 기능인 '내 PC의 자막 파일 열기'를 통해 **사용자가 직접 가져오기**가 가능한 범위다. 원본의 현재 재생 회차·자동 자막 삽입·ChatGPT 자동 요청은 연동 API 없이 보장할 수 없다.
4. **사용성:** 작은 별도 Companion 창/트레이 런처를 우선 검토한다. 원본 창 위에 코드를 주입하거나 원본 프로세스 메모리/세션을 읽거나 OS 입력 자동화에 의존하지 않는다.
5. **미래 인앱 통합:** 꼭 원본 안에 탭과 버튼이 보여야 한다면 원본 제작자가 허용하는 버전형 플러그인/IPC 인터페이스가 필요하다. upstream에 공식 확장 API 추가가 합의될 때만 연동한다. 업데이트 후 원본 `app.asar`를 자동 패치하는 방식은 원본 무변경 및 자동 업데이트 유지 목표와 충돌하므로 기본 방식으로 채택하지 않는다.

## 구현 가능 수준을 혼동하지 말 것

- **가능:** 원본 업데이트 그대로 유지, 별도 창에서 분기/요일표와 공급원 확인, 자막 파일 프롬프트 생성 및 내보내기(구현 후), 독립 프로필.
- **현재 증명되지 않음:** 원본 LilacAnime 내부 화면에 우리 탭/버튼 추가, 원본의 현재 회차/자막 자동 읽기, 원본 재생을 Companion에서 자동 제어, 원본에 자동 자막 적용.
- **하지 않음:** 원본 교체 설치, `app.asar` 변조, DLL/스크립트 인젝션, 쿠키/토큰 추출, 공식 제공되지 않는 ChatGPT 웹 자동화.
- **검증과 구현은 다름:** 이 문서는 구조 조사일 뿐, Companion 실행 프로그램은 아직 만들지 않았다.

## 다음 Codex 작업 (구현 전 안전 게이트)

1. 원본 `v0.5.14`와 설치본의 공식 확장점·딥링크·외부 IPC 존재 여부를 읽기 전용으로 재확인한다. 조사 가능한 근거(파일/라인/버전)를 기록한다.
2. `codex/companion-prototype`를 통합본 `4610a45`에서 분기하고 독립 `companion/` 디렉터리에 최소 실행 프로토타입을 만든다. **원본과 동일한 앱 ID·프로필을 절대 사용하지 않는다.**
3. 첫 단계는 기존 순수 함수/프롬프트를 재사용한 **모의 데이터 기반** 월~일/분기 화면과 사용자 지정 자막 파일 번역 보조/내보내기만 검증한다. 실제 공급원/ChatGPT 연결은 별도 승인·조건 확인 뒤다.
4. 원본 설치본 실행 시에도 읽기/쓰기 충돌이 없는지 확인한다. 원본 데이터 경로에 대한 쓰기 시도 = 테스트 실패.
5. Companion 자체 테스트, 격리 Windows 실행 테스트, 원본 v0.5.14 업데이트 이후에도 독립 실행 가능 여부를 구분해 기록한다. 실제 호환성 시험을 수행하지 않았으면 '미검증'으로 둔다.
6. 검증 보고에 *별도 창으로 가능한 기능 / 공식 확장이 필요한 원본 내 기능*을 나누고, 자동 업데이트 호환성의 한계를 분명히 쓴다.

## 보호·인수 조건

- `main`, 원본 upstream, 기존 패치 01/02/통합 브랜치는 변경하지 않는다.
- 설치, 제거, 강제 Git 조작, 프로필 마이그레이션, 원본 데이터 직접 읽기/쓰기는 승인 없이 수행하지 않는다.
- `next episode autoplay`를 새로 도입하지 않는다.
- 사용자가 말한 '애드온'을 기존 LilacAnime와 별도로 설치되는 **대체 플레이어**로 해석하지 않는다.
- 향후 Companion 실제 UI의 범위가 확정되기 전에는 완전한 인앱 통합이라고 보고하지 않는다.
