# Codex 첫 작업 지시문

LilacAnime Desktop을 기반으로 Windows 먼저, Android 나중에 개발하는 프로젝트다.

전체 요구사항과 우선순위는 첨부한 `CODEX_MASTER_PLAN.md`에 있다. 먼저 그 문서를 끝까지 읽어라.

**첫 작업은 코드를 고치는 것이 아니라 원본 프로젝트의 실행 기준선을 점검하는 것이다.**

1. 원본 저장소 `https://github.com/whispelyn-byte/LilacAnime-desktop` 및 현재 작업 디렉터리를 점검하고, 기존 코드와 자료를 임의로 삭제하거나 덮어쓰지 마라.
2. README, PRODUCT.md, DESIGN.md, package.json, `electron/`, `src/`, `tests/` 등을 분석하라.
3. 가능한 환경에서 의존성 설치, 앱 실행, 빌드, 자동 테스트를 수행하고 **실제 실행한 명령 및 결과**를 기록하라. 네트워크·권한·사이트 접근 제한으로 검증하지 못한 항목은 성공으로 표시하지 마라.
4. 확정한 1~42번 요구사항과 현재 구현을 대조해 `이미 지원 / 수정 필요 / 신규 개발 / 기술 검증 필요 / 보류`로 분류하라. 24번 자막 편집기는 제외, 28번 다음 화 자동 재생은 금지, 43번 배포 결정은 보류한다.
5. Windows에서 `검색 → 작품 선택 → 회차 선택 → 실제 재생 → 한국어 자막 자동 적용 → 마지막 위치 이어보기` 흐름을 먼저 안정화하는 최소 수정 로드맵을 작성하라.
6. 원본 코드와 자료의 이용허락, 외부 영상·자막 출처의 이용 조건을 점검하라. 우회 방법이나 권리 침해를 가정한 구현을 하지 마라.
7. API 없는 ChatGPT 자동 번역과 일본어 음성 기반 의미 비교 자동 싱크는 **검증 전 목표**로 분류하고 당장 동작한다고 주장하지 마라.
8. 필요한 산출물은 `docs/BASELINE_AUDIT.md`, `docs/FEATURE_GAP.md`, `docs/PHASE1_PLAN.md` 세 가지다. 먼저 이 보고서들을 제출하고 나서 코드 변경에 들어간다.

우리 앱의 핵심 목표는 **복잡한 설정 없이 애니메이션을 편하게 시청하는 것**이다. 코드를 크게 재작성하거나 사용자가 조작해야 할 새 UI를 함부로 늘리지 마라.
