# DinoPatch Beta 9 사용자 설명서

## 제품과 버전

DinoPatch `0.2.0-beta.9`는 LilacAnime Desktop과 별도로 실행하는 비공식 Windows x64 관리자입니다. LilacAnime 소스 폴더에 파일을 넣는 기존 Beta 7 절차를 사용하지 않습니다. 관리자 버전과 LilacAnime 앱 버전은 서로 다른 번호 체계입니다.

검증 기준은 공식 LilacAnime v0.5.65 `app.asar`입니다. 관리자는 버전 이름만으로 호환을 승인하지 않고 실제 원본 식별 정보, 파일 구조, 기록, 해시와 백업을 검사합니다. 따라서 버전 문자열이 같아도 사용자 수정이나 다른 배포판으로 인해 차단될 수 있습니다. 검증 기준을 통과한다고 모든 LilacAnime 버전과 수정본이 지원되는 것은 아닙니다.

## 설치

1. 제공된 ZIP을 별도 폴더에 풉니다.
2. `dino-native-manager.exe`와 `dino-native-updater.exe`를 같은 폴더에 둡니다.
3. LilacAnime를 완전히 종료한 뒤 관리자를 실행합니다.
4. `LilacAnime.exe`와 `resources\app.asar`가 있는 설치 폴더를 선택합니다. 저장소, 소스 checkout 또는 `app.asar` 파일 자체를 선택하지 마세요.
5. 상태 검사 결과와 설치 경로를 확인한 뒤 지원 조합만 적용합니다.

현재 Beta 9의 지원 기준은 공식 v0.5.65 구조 및 관리자에 등록된 지문입니다. 불일치·충돌·복구 대기 상태를 발견하면 적용을 중단하고 진단 정보를 복사해 지원을 요청하세요. 이 안내는 관리자의 검사를 대신하지 않습니다.

## 패치 선택

| ID | 기능 | Beta 9 신규 설치 |
|---|---|---|
| 01 | 통합 검색·공급원 전환 | 지원. 실제 공급원 검색·상세·회차·재생 연결은 일부 미검증 |
| 02 | 야애니 전용 탭 | 지원. 명시적인 Hentai 분류를 사용하며, 실제 카탈로그 자동 분류 검증은 미완료 |
| 03 | 2배속 버퍼링 최적화 | 보류. 성능 개선이 재현되지 않아 신규 적용 비활성화 |

지원 신규 조합은 `01`, `02`, `01+02`입니다. 03을 포함한 과거 등록 조합은 상태 확인과 안전한 전환·해제·원복을 위한 호환 목적으로만 인식될 수 있습니다. 과거 조합이 인식된다는 사실은 03의 현재 성능을 보증하지 않습니다.

체크한 항목은 선택 목표이고, `적용됨`은 실제 설치 파일과 기록을 검사한 상태입니다. 두 상태를 구분하세요. 체크박스만 바꾸는 것은 파일을 변경하지 않습니다. 빈 선택으로 전체 해제가 가능하다고 가정하지 말고, 관리자에 표시되는 안전한 해제 동작을 사용하세요.

## 자동 검사와 자동 적용

- 자동 상태 검사는 읽기 전용이며 자동 적용 설정과 별개입니다.
- 자동 적용은 선택한 **확정 구성**을 대상으로 하며, 지원 조합·검증된 원본·일치하는 기록·정상 백업 등 안전 조건을 모두 통과해야 합니다.
- 원본 없음, 미지원 구조, 충돌, 백업 오류 또는 복구 대기에서는 적용을 보류합니다. 차단 메시지를 우회하지 마세요.
- 처음 사용하거나 동작을 확인하는 동안에는 자동 적용을 끄고 상태부터 확인하는 편이 안전합니다.

## 백업, 해제 및 복원

패치를 적용하기 전에 관리자는 원본과 기록을 검증하고 복구 데이터를 준비합니다. 복원은 표시된 백업을 선택한 뒤 확인 대화상자에서 진행합니다. LilacAnime가 실행 중이거나 기록·파일 해시가 맞지 않으면 종료하거나 복원을 시도하지 말고 관리자 안내에 따르세요. `app.asar`, 설치 기록, 백업 파일을 직접 교체·삭제·이름 변경하지 마세요.

## 업데이트

관리자의 업데이트 확인은 `dinoforge/lilac-dino-patch`의 공개 GitHub Releases를 조회합니다. 설치 시 버전·자산 이름·GitHub API digest와 실제 다운로드 파일의 SHA-256을 검사하고 사용자 승인을 요구합니다. API digest 대조만으로 전자서명 또는 GitHub Attestation 검증이 되는 것은 아닙니다. 공개 feed에 현재 관리자보다 높은 Beta 자산이 없거나 저장소 조회에 실패하면 온라인 업데이트는 제공되지 않습니다. 현재 RC를 이미 게시된 다운로드로 간주하지 마세요.

## 알려진 제한

- 실제 Windows 화면에서 최신 RC UI를 최종 확인하지 않았습니다.
- 실제 RE:Anime/Animenosub 검색, 공급원 전환, 상세·회차, 영상 재생을 완전히 확인하지 않았습니다. 공급원 오류는 패치 결함과 구분해야 합니다.
- 신뢰된 실제 작품 ID와 분류 메타데이터가 연결된 자동 Hentai 분류 사례를 아직 확보하지 못했습니다. `Ecchi`, 제목, 연령 등급만으로 작품을 포함하지 않습니다.
- 2배속 최적화는 개선을 입증하지 못해 신규 설치가 보류 상태입니다.
- 이 RC는 공식 LilacAnime 릴리스가 아니며, 앱 전체 호환·재생·성능을 보증하지 않습니다.

## 문제 보고

관리자에서 진단 및 로그 복사 기능을 사용하고, 패치 ID, 관리자 버전, 표시된 상태, 발생 단계와 비식별 오류 메시지를 함께 기록하세요. 로그에는 개인 경로나 설치 정보가 포함될 수 있으므로 공개하기 전에 직접 확인해 민감한 내용을 제거하세요. 충돌을 해결하려고 파일을 직접 수정하지 마세요.
