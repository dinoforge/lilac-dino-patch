# 라일락 디노 패치 사용자 설명서

**Lilac Dino Patch**는 공식 LilacAnime Desktop에 통합 검색과 공급원 선택 기능을 추가하고, 패치 적용·해제·복원을 관리하는 Windows 프로그램입니다.

> **지원 환경:** Windows x64 · 공식 LilacAnime **소스 폴더** 필요  
> **배포 상태:** GitHub용 Windows ZIP 릴리즈는 아직 게시되지 않았습니다. 이 문서는 검토된 A/B 소스 기준입니다.

[공식 LilacAnime Desktop](https://github.com/whispelyn-byte/LilacAnime-desktop) · [라일락 디노 패치](https://github.com/dinoforge/lilac-dino-patch)

## 1. 설치 전 확인

- 공식 소스 폴더 안에 `package.json`, `src/`, `electron/`이 있어야 합니다. **일반 설치 프로그램으로 설치한 앱 폴더나 `app.asar`만으로는 패치할 수 없습니다.**
- 공식 LilacAnime를 완전히 종료하고, 중요한 소스 파일과 개인 자료는 별도로 백업하세요.
- 관리자는 버전 번호뿐 아니라 파일 지문과 연결 구조도 검사합니다. 호환성이 확인되지 않으면 적용하지 않습니다.
- 공식 v0.5.58이 주요 검증 기준이며, 모든 버전에서의 정상 동작을 보장하지 않습니다.

## 2. 설치 및 첫 실행

배포가 승인되고 무결성이 확인된 ZIP을 받은 경우, 압축을 풀어 **`DinoPatchManager` 폴더 전체**를 공식 소스 루트에 넣습니다.

```text
LilacAnime-source/
├── package.json
├── src/
├── electron/
└── DinoPatchManager/
    ├── 디노패치관리자.exe
    └── resources/
        ├── app.asar
        ├── manager-engine/
        └── manager-node/
```

1. `디노패치관리자.exe`를 실행합니다. 실행 파일만 다른 곳으로 옮기지 마세요.
2. 상단의 **원본 폴더**가 올바른 LilacAnime 소스 루트인지 확인합니다.
3. 자동으로 인식하지 못했다면 **원본 폴더 변경**을 눌러 지정합니다.
4. 관리자가 호환성을 검사합니다. 지원되는 미적용 원본이면 변경 파일을 백업한 뒤 **자동으로 패치를 적용**합니다.
5. **패치 목록**과 화면 아래 **작업 상태**에서 결과를 확인합니다.

**중요:** `원본 폴더 변경` 또는 `원본 다시 확인`은 단순 조회로 끝나지 않을 수 있습니다. 조건이 맞으면 자동 적용까지 진행합니다.

## 3. 적용 후 사용하기

패치가 정상 적용되면 공식 LilacAnime 화면 안에서 다음 기능을 이용할 수 있습니다.

- 여러 공급원의 검색 결과를 한곳에서 확인
- 같은 작품으로 판단되는 검색 결과 묶기
- 작품별 공급원 선택 및 전환
- 공식 작품 상세·회차·플레이어 흐름 이용

외부 공급원 사정에 따라 검색 결과나 영상·자막 이용 가능 여부는 달라질 수 있습니다.

## 4. 패치 해제 및 백업 복원

### 패치 해제

1. 관리자에서 패치 상태가 **적용됨**인지 확인합니다.
2. **고급 도구 → 디노 패치 해제**를 선택합니다.
3. 확인창에서 승인하면 관리자가 소유한 패치 변경을 제거하고 공식 소스 파일을 복원합니다.
4. **작업 상태**가 미적용으로 변경됐는지 확인합니다.

사용자가 직접 해제하면 **동일한 공식 소스에서는 재시작해도 자동 재적용하지 않습니다.** 공식 소스가 바뀌면 다시 검사하고, 조건에 따라 자동 적용할 수 있습니다.

**현재 검토된 버전에는 GUI의 수동 '다시 적용' 버튼이 없습니다.** 숨겨진 개발 명령이나 파일 수동 교체로 재적용을 시도하지 마세요.

### 백업 복원

**고급 도구 → 백업 및 작업 기록**에서 복원 가능한 백업을 선택하고 **백업 복원**을 누릅니다. 관리자는 복원 전에 파일 상태와 지문을 확인하며, 충돌이 있으면 작업을 중단할 수 있습니다.

패치 해제와 백업 복원은 **패치가 관리하는 공식 소스 파일**을 대상으로 합니다. 사용자 AppData, 설정 전체, 시청 기록 또는 공식 앱 설치 자체를 복원하는 기능은 아닙니다.

## 5. 문제가 생겼을 때

| 화면 표시 또는 상황 | 확인할 사항 |
| --- | --- |
| **원본 미발견** | `package.json`, `src/`, `electron/`이 있는 소스 루트를 선택했는지 확인하세요. |
| **소스 비호환 / 호환성 확인 필요** | 공식 버전과 파일 구조가 지원 범위인지 확인하세요. 검사 우회는 하지 마세요. |
| **파일 충돌 / 상태 확인 필요** | 사용자 수정 파일이 있는지 확인하고, **진단 정보**와 **상세 작업 로그**를 살펴보세요. 임의로 덮어쓰지 마세요. |
| **LilacAnime 실행 중** | 공식 앱을 정상 종료한 뒤 다시 확인하세요. |
| **해제 후 자동 적용되지 않음** | 수동 해제 상태에서는 의도적으로 자동 재적용이 억제됩니다. |
| **공식 새 버전 발견, 설치 안 됨** | **최신 버전 확인**은 조회 기능입니다. 원본 다운로드·설치·업그레이드는 지원하지 않습니다. |

과거 패치에서 공식 설정의 `contentSource`에 `integrated`가 저장된 경우, 복구할 이전 공급원 기록이 없으면 관리자가 값을 임의로 변경하지 않습니다. **공식 앱 설정 화면을 이용할 수 있다면** 지원되는 공급원을 직접 선택해 저장하세요. 사용자 프로필 전체 삭제나 Chromium LevelDB 직접 수정은 권장하지 않습니다.

## 6. 기록 및 지원 정보

**고급 도구**에는 `원본 다시 확인`, `작업 기록`, `진단 정보`, `상세 작업 로그`가 있습니다.

문제를 공유할 때는 관리자 버전, 공식 앱 버전, 패치 상태와 오류 메시지를 알려주세요. 경로에 포함된 사용자 이름, 토큰, 개인 기록은 가린 뒤 전달하세요.

## 현재 버전의 제한

- GitHub Windows 배포 ZIP은 **아직 게시되지 않았습니다.**
- 수동 재적용 GUI와 근거 없는 과거 설정의 확인형 복구 UI는 **포함되지 않습니다.**
- 전체 기능적 융합 검증은 **PARTIAL**이며, 모든 공식 앱 버전·외부 공급원의 동작을 보장하지 않습니다.
- 이 프로젝트는 공식 LilacAnime의 **비공식 독립 패치 관리자**입니다.
