# 라일락 디노 패치 사용자 설명서

> **Windows x64용 비공식 LilacAnime Desktop 패치 관리자**
>
> 이 설명서는 A/B 변경이 포함된 검토 소스 기준입니다. **GitHub의 Windows ZIP 릴리즈는 아직 게시되지 않았습니다.** 다운로드 주소나 설치 파일을 임의로 추측하지 마세요.

공식 원본: https://github.com/whispelyn-byte/LilacAnime-desktop

디노 패치: https://github.com/dinoforge/lilac-dino-patch

## 1. 사용 전 확인

- 이 프로그램은 LilacAnime Desktop **소스 폴더**를 대상으로 합니다. 일반 설치 프로그램으로 설치한 앱의 app.asar만으로는 적용할 수 없습니다.
- 지원하는 Windows 환경은 x64입니다.
- 대상 소스 루트에는 package.json, src 폴더, electron 폴더가 있어야 합니다.
- 호환성 검사와 파일 지문 검사를 통과한 원본에만 적용합니다. v0.5.58은 검증 기준이지만 모든 버전을 지원하는 것은 아닙니다.
- 실행 중인 공식 LilacAnime 앱을 종료하고, 중요한 사용자 자료와 원본 소스를 별도로 백업해 두는 것이 좋습니다.
- 관리자가 지원하지 않는 소스를 감지하면 검사를 건너뛰거나 파일을 직접 덮어쓰지 마세요.

## 2. 폴더 배치

배포가 허가되고 무결성이 확인된 ZIP 안의 **DinoPatchManager 폴더 전체**를 공식 소스 루트에 배치합니다.

~~~text
LilacAnime-source/
├── package.json
├── src/
├── electron/
└── DinoPatchManager/
    ├── 디노패치관리자.exe
    ├── resources/
    │   ├── app.asar
    │   ├── manager-engine/
    │   └── manager-node/
    └── runtime/  (실행 시 사용하는 관리자 데이터)
~~~

실행 파일만 떼어 내지 않고 **디노패치관리자.exe**를 실행합니다. 제대로 패키징된 관리자에는 전용 Python 엔진과 필요한 런타임이 포함되므로 일반 이용자가 별도 Python 환경을 설치할 필요는 없습니다.

현재 이 저장소에 다운로드용 GitHub Release ZIP은 게시되지 않았습니다. 위 구조는 배포 파일이 확보됐을 때의 설치 예시입니다.

## 3. 처음 실행하기

1. 디노 패치 관리자를 실행합니다.
2. 상단의 **LilacAnime 버전**과 **원본 폴더**에 표시된 경로가 내가 사용하려는 소스 루트인지 확인합니다.
3. 자동으로 찾지 못한 경우 **원본 폴더 변경** 버튼을 눌러 공식 소스 루트를 선택합니다.
4. 관리자는 원본 구조, 공식 지문, 기존 적용 기록과 호환성을 검사합니다.
5. 호환되는 미적용 원본이라면 필요한 파일을 백업하고 패치를 **자동으로 적용**합니다.
6. **패치 목록**에서 상태를 확인합니다. '적용됨 · 호환'이나 '적용됨 · 구조 확인'은 정상 적용 상태를 나타냅니다.
7. 화면 아래 **작업 상태**에서 결과를 확인합니다. '파일 충돌', '소스 비호환', '상태 확인 필요' 등이 표시되면 원본을 임의로 수정하지 마세요.

**주의:** '원본 다시 확인' 및 '원본 폴더 변경' 뒤의 절차는 읽기 전용 조회가 아니라 조건을 만족하면 **자동 적용**까지 진행할 수 있습니다.

## 4. 패치가 제공하는 기능

호환되는 공식 소스에 패치가 적용되면 디노 통합 검색과 동일 작품 묶기, 작품별 공급원 선택을 지원합니다. 작품 상세, 회차 선택 및 재생 진입점은 원본 LilacAnime의 흐름을 활용합니다.

기존 홈·주간표·원본 앱 설정과의 공존을 목표로 하지만 공급원 사이트 변경이나 영상 링크 사정으로 일부 검색·재생이 실패할 수 있습니다. 외부 콘텐츠 서비스의 이용 조건을 준수하세요.

최근 설정 변경에서는 디노 통합 모드 선택을 **디노 전용 키**에 저장합니다. 공식 LilacAnime가 사용하는 contentSource에 새로운 integrated 값을 기록하지 않습니다.

## 5. 패치 해제하기

1. 관리자에서 공식 소스 경로와 **적용됨** 상태를 확인합니다.
2. **고급 도구**를 펼칩니다.
3. **디노 패치 해제**를 누릅니다.
4. 확인창에서 작업 대상을 확인하고 승인하거나 취소합니다. 취소하면 패치 적용 상태가 유지됩니다.
5. 해제에 성공하면 관리자가 소유한 변경 파일을 공식 소스로 복원하고 패치 모듈을 제거합니다.
6. **작업 상태**가 미적용으로 바뀌었는지 확인합니다.

사용자가 직접 해제한 **동일한 공식 소스**에서는 관리자를 다시 실행해도 자동으로 패치를 적용하지 않도록 설계됐습니다. 공식 원본 소스가 변경되면 다시 호환성을 검사하며 조건에 따라 자동 적용할 수 있습니다.

**중요:** 이 버전의 관리자 GUI에는 수동 해제 후 사용자가 클릭할 **'다시 적용' 버튼이 없습니다.** 별도의 미검증 GUI 실험 코드가 존재하지만 이 검토된 배포 후보에는 포함되어 있지 않습니다. 재적용을 위해 개발자 IPC나 숨겨진 명령을 실행하지 마세요.

## 6. 백업과 복원

**고급 도구 → 백업 및 작업 기록**에서 복원 가능한 백업을 선택하고 **백업 복원**을 누를 수 있습니다. 복원 실행에는 확인창과 현재 파일 상태·지문 검사가 적용됩니다.

- 이미 복원이 완료된 백업은 기록으로 남더라도 다시 복원 가능한 항목에 표시되지 않을 수 있습니다.
- 사용자나 다른 프로그램이 공식 파일을 예상과 다르게 변경했다면 안전을 위해 복원을 중단할 수 있습니다.
- '패치 해제'는 **패치가 수정한 공식 소스 파일**의 복원입니다. 앱 전체 재설치, 사용자 AppData, 시청 기록, 즐겨찾기 및 모든 localStorage의 복원을 의미하지 않습니다.

## 7. 문제 해결

**원본 폴더를 찾지 못했습니다**

공식 앱의 설치 폴더나 EXE만 선택한 것은 아닌지 확인합니다. package.json, src, electron이 들어 있는 공식 **소스 루트**를 지정하세요.

**소스 비호환 / 파일 충돌 / 호환성 확인 필요**

다른 공식 버전이거나 파일이 변경됐을 수 있습니다. 지문 검사를 우회하거나 임의의 파일로 덮어쓰지 마세요. 관리자 '진단 정보'와 '상세 작업 로그'를 확인합니다. Windows checkout의 LF/CRLF 차이도 공식 지문 불일치의 원인이 될 수 있습니다.

**LilacAnime가 실행 중입니다**

공식 앱을 정상 종료하고 관리자에서 상태를 다시 확인하세요. 프로그램을 강제 종료하거나 실행 중인 원본 파일을 수동 교체하지 마세요.

**패치를 해제했는데 다시 자동 적용되지 않습니다**

사용자가 수동 해제한 동일한 소스에서 자동 재적용을 막는 것은 의도된 보호 동작입니다. 현재 배포 후보의 GUI에는 명시적 재적용 버튼이 없습니다.

**패치 해제 후 기존 통합 검색 공급원 값이 남아 있습니다**

과거 버전이 localStorage.contentSource에 integrated를 저장했다면 원본 LilacAnime가 지원하지 않는 값이 남아 있을 수 있습니다. 복구 가능한 이전 공식 공급원 기록이 없으면 관리자가 값을 임의로 추측해 저장하지 않습니다. 공식 앱의 설정 화면이 열리는 경우, 사용자가 공식 지원 공급원을 직접 선택해 저장하는 경로가 있습니다. 원본 사용자 프로필 전체를 삭제하거나 Chromium LevelDB를 외부 프로그램으로 직접 편집하지 마세요.

**최근 공식 버전을 찾았는데 업데이트가 되지 않습니다**

관리자의 **최신 버전 확인**은 공식 릴리즈 조회 기능입니다. 원본 소스 자동 다운로드·설치나 NSIS 설치 앱 업그레이드를 지원하지 않습니다.

## 8. 작업 기록과 진단

**고급 도구**에서 '작업 기록', '진단 정보', '상세 작업 로그'를 통해 결과와 원인을 확인할 수 있습니다. 문제를 보고할 때는 관리자 버전, 공식 소스 버전, 표시된 상태와 오류 문구를 제공하되, 사용자 경로·개인정보·토큰·시청 기록은 제거하세요.

## 9. 현재 배포 후보의 한계

- A/B 기능 수정 소스는 검증됐지만 GitHub의 **새 관리자 ZIP 릴리즈는 아직 미게시** 상태입니다.
- GUI 수동 재적용 버튼은 포함되지 않습니다.
- 사용자 확인형 legacy 설정 복구 UI는 포함되지 않습니다.
- 모든 공식 버전, 사용자 프로필, 외부 영상·자막 공급원의 실제 동작을 보증하지 않습니다.
- 전체 기능적 융합 판정은 PARTIAL입니다.

개발·빌드 담당자는 [Windows 배포 실행 절차](releases/RELEASE_OPERATIONS.md)를, 프로젝트 관계는 [공식 원본 연결 안내](UPSTREAM_LINK.md)를 참조하세요.
