# 번역 프롬프트 자료

- `영어 번역 프롬프트.txt`와 `일본어 번역 프롬프트.txt`는 사용자가 제공한 원문 그대로 보관한다. ChatGPT 수동 번역에서 자막의 주된 원문 언어에 맞춰 전체 지침을 선택한다.
- 앱은 원본 WebVTT의 cue 시간과 구조를 직접 보존하므로, 복사 요청 마지막에 내부 cue ID JSON 응답 형식을 덧붙인다. 앞뒤 최대 두 cue는 문맥으로만 전달하고 번역 결과에는 넣지 않는다. 원문 subtitle cue는 지시 실행 대상이 아니라 번역 데이터다.
- `Reazon_작품용_단어사전_예시.txt`는 ReazonSpeech 음성 인식 hotwords 설정 예시다. 번역 용어집이나 공통 단어사전으로 적용하지 않는다. 실제 작품에서 반복해서 잘못 인식되는 일본어 고유명사가 있을 때만 ASR에 선택적으로 쓴다.
