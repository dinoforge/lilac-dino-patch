# DinoPatch Beta 8 — 3·4·5·11·12·15 기능 선택 개발 기록

이 문서는 정식 배포 승인이 아니라 기존 최종 후보에서 분기한 기능 개발의 진행 상황입니다.
기존 공식 LilacAnime 설치본, 사용자 SQLite 원본 및 이전 Beta 8 PREVIEW EXE는 변경하지 않았습니다.

## 적용 범위

| 번호 | 기능 | 이번 소스 작업 | 한계 |
|---|---|---|---|
| 3 | 통합 검색 속도 | 기존 병렬 검색/90초 공급원 응답 캐시·6시간 로컬 검색 캐시를 유지하면서 언어별 요청을 공급원 간 라운드로빈으로 배분 | 검색 속도·속도 향상률은 실제 공급원에서 측정하지 않음 |
| 4 | 중복 작품 자동 병합 | 기존 AniList/MAL ID 및 엄격한 연도·시즌·포맷 확인 병합 유지, 검색 상태에 자동 묶음 공급원 수 표시 | 이름만 비슷하거나 연도·시즌이 모호한 작품을 강제 병합하지 않음 |

## 안전성 조건

- 다국어 이름만으로 서로 다른 작품이나 시즌을 병합하지 않습니다. 이미 저장된 수동 제목·분리 기록은 유지합니다.
- 새 작품 관측은 공식 화면이 전달한 항목만 사용합니다. 방영일이 부정확하거나 미래·90일 이전 날짜는 제외합니다.
- 진단에는 공급원 상태 개수만 사용하며 쿼리, 작품명, 파일 경로, 재생 URL 및 외부 오류 본문을 보여주거나 내보내지 않습니다.
- 색상 설정은 `lilacDinoPatch.integratedAccent.v1`, 신작 관측 기록은 `lilacDinoPatch.newSeasonObserved.v1` 키에만 저장합니다.
- 패치 관리자 업데이트 페이지는 외부 GitHub 릴리스 정보 확인용입니다. 저장소가 비공개이거나 정식 릴리스가 없다면 최신 버전 여부를 자동 판단할 수 없습니다. 자동 다운로드는 없습니다.

## 회귀 검사

- 새 `tests/dino-beta8-selected-features.test.cjs` 7개를 릴리스 사전 점검에 추가했습니다.
- `tests/patch03-global-integration.test.cjs`에 통합 색상 설정 및 신작 관측 UI 테스트 2개를 추가했습니다.
- 새 검색 엔진 코드를 독립 JavaScript 런타임에서 직접 호출한 핵심 7개 점검은 모두 통과했습니다.
- `patches/patch03/manifest.json`의 통합 검색 JS·CSS·브리지 세 파일 SHA-256을 실제 소스 바이트로 다시 계산하여 반영했습니다.

**아직 통과로 보고하지 않는 항목:** 저장소 전체 Node.js 회귀 실행, Rust GUI 포맷/컴파일,
Windows 실사용 화면, 공식 공급원별 라이브 검색·회차·재생, 정식 업데이트 채널과 자동 버전 비교입니다.
CI 및 EXE 재빌드는 이번 기능 개발 단계에서 실행하지 않았습니다.

## 추가 작업

1. PowerShell 진단 수정 브랜치 테스트를 마저 통과시킵니다.
2. Node.js 전체 회귀, 통합 UI 테스트, Rust 관리자 테스트를 격리 환경에서 실행합니다.
3. 라이브 공급원 5개 검색 속도와 오분류율을 측정하며 캐시·동시성 한도를 검증합니다.
4. 별도 사용자가 검토할 수 있는 공개 또는 인증된 DinoPatch 릴리스 메타데이터 채널을 결정합니다.
5. 릴리스 버전 비교·선택형 자동 알림은 채널이 정해진 뒤 별도 구현하고, 서명/해시 확인 없는 자동 설치는 하지 않습니다.
6. 실제 Windows 설치 복사본에서 적용→통합 검색→재생→원복을 검증한 뒤에만 새 EXE를 빌드·배포합니다.
