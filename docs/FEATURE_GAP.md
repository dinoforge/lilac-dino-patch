# 요구사항 1–42 구현 차이

기준: docs/planning/CODEX_MASTER_PLAN.md의 확정 요구사항. 분류는 소스·문서의 정적 구현 확인이며, 실제 서비스 연동이나 출시 품질 검증을 뜻하지 않는다.

## 분류 기준

- 이미 지원: 관련 코드 경로가 존재한다. 필요하면 표에 실제 검증 한계를 덧붙인다.
- 수정 필요: 일부 구현은 있으나 요구 UX·범위·동작과 충돌하거나 빠진 부분이 있다.
- 신규 개발: 구현 근거를 찾지 못했다.
- 기술 검증 필요: 실제 자료·사이트·기기·품질 확인이 통과 조건이다.
- 보류: 사용자 또는 외부 권리·서비스 선택이 먼저 필요하다.

## 1–42 매트릭스

| 번호 | 상태 | 현재 구현 및 차이 |
|---:|---|---|
| 1 | 수정 필요 | Electron Windows 앱과 macOS 빌드가 있다. Android 앱은 없다. 이 프로젝트 범위는 Windows 우선 후 Android이며 macOS·Chrome은 제외한다. |
| 2 | 기술 검증 필요 | 현재 공급원은 RE:Anime, Miruro, Animenosub, 애니24, Linkkf다. LinkAni 선택지와 어댑터는 제거했다. 공급원별 현재 응답·권한·이용 조건은 미검증이다. |
| 3 | 수정 필요 | 홈에 연도와 1~4분기 선택 및 최근 방영 회차 레일을 추가했다. 분기 필터·캐시는 RE:Anime·Miruro·Animenosub만 지원하며, 최근 회차 레일은 AniList ID와 현재 공급원의 회차 수를 함께 확인하는 RE:Anime·Miruro만 지원한다. 카드를 누르면 공급원 상세에서 같은 회차가 재생 가능한지 다시 검사한다. 최신 회차 결과는 30분 캐시와 12시간 이내 저장본 복구를 쓴다. Linkkf·애니24는 확인된 과거 분기 날짜가 없어 분류하지 않으며, 최신 회차 연결도 미완성이다. 실제 공급원 응답·재생은 미검증이다. |
| 4 | 수정 필요 | TMDB → AniList → Wikidata 제목 조회와 다국어 검색은 구현돼 있다. 설정에서 영어 표시도 가능해 한국어 우선·원제 보조라는 목표에 맞춰 기본 표시와 선택지를 정리해야 한다. 실제 제목·시즌 오매칭 검증도 남아 있다. |
| 5 | 기술 검증 필요 | 사이트 트랙과 Kairan·Csora·Anissia 자막 검색·적용 코드가 있고, 플레이어에서 현재 회차의 검색 상태를 출처별로 표시한다. 저장된 자막은 재실행 뒤에도 있음으로 표시한다. 실제 검색 결과·정확한 시즌·회차·영상판 일치와 오적용 방지는 검증되지 않았다. |
| 6 | 수정 필요 | 로컬 AI 및 번역 API 경로는 있다. 계획의 수동 ChatGPT 복사·붙여넣기 결과 가져오기 흐름은 찾지 못했고, API 사용을 필수로 둘 수 없다. |
| 7 | 신규 개발 | 일본어 음성과 자막 문장의 의미 비교를 통한 구간별 자동 싱크 구현은 없다. 기존 OP/ED 오디오 fingerprint는 자막 싱크 기능이 아니다. |
| 8 | 이미 지원 | 사용자 SRT·SMI·ASS·SSA·VTT 선택과 ASS/SSA 렌더링 코드가 있다. 각 형식과 특수 스타일의 실파일 검증은 남아 있다. |
| 9 | 기술 검증 필요 | 재생·탐색·화질·속도·자막·화면비·OP/ED·이어보기와 수동 다음 화 선택 코드가 있다. 실제 설치 앱의 전체 재생 흐름은 미검증이다. |
| 10 | 기술 검증 필요 | 다운로드 큐, 재시도·재개 및 오프라인 보관함 코드가 있다. 허용된 콘텐츠로 다운로드와 자막 포함 재생을 검증하지 않았다. |
| 11 | 신규 개발 | 현재 기록·설정은 로컬 저장이다. Windows와 Android 간 기록·설정·프로필 동기화는 없다. |
| 12 | 수정 필요 | 업데이트 확인·다운로드 구현은 있지만 원본 저장소를 가리킨다. 자동 백업과 수동 내보내기·가져오기·복구 구현은 확인하지 못했다. |
| 13 | 신규 개발 | 관리형 클라우드 계정·동기화는 없다. Supabase/Firebase 등은 선택되지 않았다. |
| 14 | 신규 개발 | 이메일·비밀번호·Google 로그인과 계정 연결 기능이 없다. |
| 15 | 신규 개발 | 기본 멀티 프로필을 확인하지 못했다. |
| 16 | 이미 지원 | 공급원 어댑터는 앱 코드에 포함되는 구조다. 임의의 외부 확장 저장소를 설치하는 기능은 확인되지 않았다. |
| 17 | 수정 필요 | 공급원별 목록·검색은 있으나 동일 작품을 안전하게 통합 카드로 묶고 불확실한 매칭을 분리하는 동작은 충족 근거가 부족하다. |
| 18 | 수정 필요 | 공급원·서버 선택과 일부 선호값 저장은 있다. 실패 후 재생 위치·자막·싱크를 확인하며 조건에 맞는 대체 서버로 자동 전환하는 전체 흐름은 검증되지 않았다. |

| 20 | 수정 필요 | 로컬 AI·용어 맥락·회차별 번역 저장 경로가 있다. 빠른 우선 표시, 번역 품질 평가와 문제 문장만 재처리하는 동작은 요구 수준으로 입증되지 않았다. |

| 24 | 이미 지원 | 별도 자막 문장·타임라인 편집기는 확인되지 않았다. 간단한 수동 싱크 조절은 있다. |

| 27 | 수정 필요 | 로컬 시청 위치와 이어보기는 있다. 계정 프로필별 Windows/Android 동기화와 처음부터 재생 선택의 전체 흐름은 미완성이다. |
| 28 | 이미 지원 | 2026-10-09 첫 Phase 1 수정에서 다음 화 자동 재생 스위치와 종료 후 자동 전환을 제거했다. 종료 시 수동 선택 안내와 컨트롤을 보이며, 단위 테스트에서 자동 전환이 없음을 확인했다. 설치 앱의 실제 종료 화면은 미검증이다. |
| 29 | 기술 검증 필요 | 이어보기 레일을 홈에서 히어로보다 위에 두고, 작품별 최근 회차 최대 6개를 150–190px 카드로 표시한다. 시작 시 다운로드 IPC 응답을 기다리기 전에 기록을 렌더링한다. 구조·스타일 자동 테스트는 통과했으나 실제 Electron 창에서 레이아웃과 사용자 기록 복구는 확인해야 한다. |
| 30 | 기술 검증 필요 | 상단·검색 화면에 자동완성과 최근 검색을 추가했다. 이미 로드한 한국어·영어·일본어 작품 제목과 최대 10개 로컬 검색어만 제안하며, 키 입력 중 외부 검색 요청은 보내지 않는다. 키보드 탐색과 전체 기록 삭제 코드 및 단위 테스트가 있다. 실제 Electron 창·스크린리더 조작은 확인해야 한다. |
| 31 | 이미 지원 | 포스터, 제목·개요·작품 정보와 회차 목록을 제공하는 상세 화면이 있다. 실제 메타데이터 정확성은 별도 검증한다. |
| 32 | 이미 지원 | 자동 숨김 플레이어 컨트롤과 통합 플레이어 설정 화면이 있다. 실제 마우스·키보드 흐름은 UI 검증이 필요하다. |
| 33 | 기술 검증 필요 | 자막 진행 상태와 오류 메시지 경로는 있다. 실제 검색·번역 실패 때 짧은 상태·재시도가 일관되는지는 검증되지 않았다. |
| 34 | 수정 필요 | 일부 공급원 재시도와 서버 선택은 있지만, 제한된 재시도 뒤 적합한 대체 서버를 자동 시도하고 끝에서만 알리는 흐름은 부족하다. |
| 35 | 이미 지원 | Windows 키보드·마우스 조작이 있다. Android 조작은 Android 단계에서 별도 구현·검증한다. |
| 36 | 이미 지원 | 원본 비율·16:9·21:9·4:3·화면 채우기 선택이 있고 로컬 테스트가 있다. Android 회전은 Android 단계다. |

| 38 | 수정 필요 | 첫 화면은 로컬 앱 흐름이며 로그인·프로필 생성 온보딩을 확인하지 못했다. 이 UX는 계정 구현 시 맞춰야 한다. |
| 39 | 기술 검증 필요 | 캐시·지연 로딩·로컬 AI 자원 관리 코드가 있다. 실제 시작 시간, 메모리·CPU/GPU 경쟁 측정은 없다. |
| 40 | 수정 필요 | Windows용 Electron이 현재 기반이며 Android는 없다. 공통 도메인 모델과 기기간 재사용 경계를 설계해야 한다. |
| 41 | 기술 검증 필요 | 로컬 플레이어·프록시 자동 테스트 10개는 통과했다. 요구된 검색→상세→실제 재생→이어보기→정확한 한국어 자막→수동 싱크 E2E는 검증되지 않았다. |
| 42 | 수정 필요 | 로컬 오류 처리 경로는 있으나 민감 정보가 제거된 진단 로그·오류 복사·사용자 주도 신고 UX는 확인 근거가 부족하다. |

## 분기 및 배포 결정

요구사항 43 설치 파일·포터블·최종 배포 결정은 계획에 따라 보류한다. 로컬 테스트용 Windows 빌드는 이미 성공했으나 공개 배포 권한이나 자동 업데이트 준비 완료를 뜻하지 않는다.
