# 요구사항 1–42 구현 차이

기준: docs/planning/CODEX_MASTER_PLAN.md의 확정 요구사항. 분류는 소스·문서의 정적 구현 확인이며, 실제 서비스 연동이나 출시 품질 검증을 뜻하지 않는다.

## 분류 기준

- 이미 지원: 관련 코드 경로가 존재한다. 필요하면 표에 실제 검증 한계를 덧붙인다.
- 수정 필요: 일부 구현은 있으나 요구 UX·범위·동작과 충돌하거나 빠진 부분이 있다.
- 신규 개발: 구현 근거를 찾지 못했다.
- 기술 검증 필요: 실제 자료·사이트·기기·품질 확인이 통과 조건이다.
- 보류: 사용자 또는 외부 권리·서비스 선택이 먼저 필요하다.

Linkkf는 요일별 방영표를 제공하며 과거 분기 날짜 기반 분류는 하지 않는다. 2026-10-09 패키지 UI의 분기·최신 방영·업데이트·오늘 요일 자동 선택과 요일 변경을 합성 IPC로 확인했다. 2026-10-10 패키지 main/preload IPC에서 세 분기 공급원(Re:Anime·Miruro·Animenosub)의 연도/분기 필터와 미재생 작품 제외, AniList의 RE:Anime·Miruro별 최신 가용 회차·캐시, Linkkf 월~일 7개 응답, Animenosub 업데이트 정렬 페이지·캐시, 애니24 `/ing` 변환을 합성 네트워크로 확인했다. 같은 패키지 renderer 스모크에서 홈의 `최근 업데이트순` 버튼을 눌러 Animenosub 합성 결과 카드의 제목·`업로드 12화`·상태 문구를 렌더링했고, 연도 입력·분기 탭 변경은 실제 `provider:quarter` main IPC까지 연결해 카드 전환을 확인했다. 이어 RE:Anime `최신 방영 회차`에서 `EP.4` 카드와 Linkkf 홈의 현재 요일 기본 선택·월요일 탭 전환도 패키지 main IPC 합성 응답으로 확인했다. 실제 공급원 응답·화수 일치·사용자 설정 전환/재시작·설치 NSIS UI는 미검증이다. |

| 9 | 기술 검증 필요 | 재생·탐색·화질·0.1–4x 속도·자막·화면비·OP/ED·이어보기와 수동 다음 화 선택 코드가 있다. 2026-10-09 임시 프로필 Electron 소스 앱에서 합성 MP4 재생, VTT 자막 표시, 재시작 후 28% 이어보기, 회차 종료 뒤 자동 전환 없음까지 확인했다. 이어서 HLS 이벤트 다섯 종류를 현재 플레이어 인스턴스에 묶고 교체 후 지연된 manifest·네트워크·미디어 오류가 새 재생에 영향을 주지 않는 회귀 테스트와 패키지 포함을 확인했다. ## 2026-10-10 추가 Phase 1 재현 검증

- Windows `package.json`과 lockfile 루트 버전을 upstream v0.5.9에 맞췄다. 로컬 NSIS 빌드에서 `app.asar/package.json` 버전 0.5.9, 설치 파일 124,555,713바이트를 확인했다. 빌드는 로컬에만 있고 실행·배포하지 않았다.
