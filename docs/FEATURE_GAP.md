# 요구사항 1–42 구현 차이

기준: docs/planning/CODEX_MASTER_PLAN.md의 확정 요구사항. 분류는 소스·문서의 정적 구현 확인이며, 실제 서비스 연동이나 출시 품질 검증을 뜻하지 않는다.

## 분류 기준

- 이미 지원: 관련 코드 경로가 존재한다. 필요하면 표에 실제 검증 한계를 덧붙인다.
- 수정 필요: 일부 구현은 있으나 요구 UX·범위·동작과 충돌하거나 빠진 부분이 있다.
- 신규 개발: 구현 근거를 찾지 못했다.
- 기술 검증 필요: 실제 자료·사이트·기기·품질 확인이 통과 조건이다.
- 보류: 사용자 또는 외부 권리·서비스 선택이 먼저 필요하다.

- Windows `package.json`과 lockfile 루트 버전을 upstream v0.5.9에 맞췄다. 로컬 NSIS 빌드에서 `app.asar/package.json` 버전 0.5.9, 설치 파일 124,555,713바이트를 확인했다. 빌드는 로컬에만 있고 실행·배포하지 않았다.
