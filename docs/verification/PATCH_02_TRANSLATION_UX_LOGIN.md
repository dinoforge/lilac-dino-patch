## 결과 요약

영어·일본어 자막을 앱 안에서 준비하고, ChatGPT 웹사이트에 수동으로 전달해 번역 결과를 검증·저장·적용하는 흐름을 보완했다. 번역 진행률은 검증을 통과한 cue 수로 계산하며, 번역 자막은 원본 시간 코드와 순서를 유지한다. 완료된 작업의 임시 데이터 정리와 미완료 작업 이어하기도 연결했다.

ChatGPT 계정 로그인과 ChatGPT 플랜을 이용한 자동 요청은 현재 사용할 수 없다. Sign in with ChatGPT 문서는 플랜 사용을 오픈소스 파트너와 선택된 비공개 클라이언트에 제공한다고 설명한다. 이 저장소는 비공개이며, 이 프로젝트가 선택된 클라이언트인지 또는 등록을 마쳤는지 확인할 근거가 없다. 따라서 앱은 가짜 로그인이나 로그인 성공 추정을 하지 않는다. [공식 SIWC Quickstart](https://developers.openai.com/siwc/quickstart)

SIWC의 계정 식별 범위는 ChatGPT 대화 접근 권한을 주지 않는다. ChatGPT 플랜 요청도 별도 Responses API 권한 동의가 필요하고, 그래도 ChatGPT 대화에는 접근하지 않는다. 별도로 허용된 대화 삭제 API와 권한도 확인되지 않아 웹 대화는 앱에서 삭제하지 않는다. [공식 SIWC Quickstart](https://developers.openai.com/siwc/quickstart), [오픈소스 토큰 공유 안내](https://developers.openai.com/siwc/token-sharing-open-source)

## 구현 내용

### 로그인 및 수동 모드

- 번역 설정에 ChatGPT 계정 연결, 로그인 상태 확인, 계정 연결 해제, 수동 번역 전환 UI를 표시한다.
- 계정 연결 및 연결 해제 버튼은 비활성화되어 있다. 로그인 상태 확인은 SIWC 자격·등록을 검증할 수 없다고 안내하며 ChatGPT 웹 로그인 상태를 읽지 않는다.
- 영어·일본어 프롬프트를 포함한 번역 요청을 클립보드에 복사하고 ChatGPT 웹사이트를 연다. 사용자가 직접 요청을 보내고 결과를 앱에 붙여넣는다.
- ChatGPT 웹 대화 정리 안내는 ChatGPT 웹사이트를 여는 기능이다. 앱은 웹 대화를 읽거나 삭제했다고 표시하지 않는다.
- 자동 ChatGPT API 요청, 비공식 요청, 쿠키·세션 접근, 토큰 추출은 추가하지 않았다.

### 진행률·묶음·응답 검증

- 작품명, 회차, 언어, 현재 묶음, 전체 묶음과 상태를 표시한다.
- 진행률은 비어 있지 않은 원문 cue 중 앱의 ID 검증을 통과한 번역 수로만 계산한다. 대기 시간에 임의로 진행률을 증가시키지 않는다.
- 영어·일본어를 문장 내용으로 판별하고, 사용자 제공 원문 프롬프트와 최대 두 cue의 앞뒤 문맥을 요청에 포함한다.
- 중복·누락·외부 ID·잘못된 JSON은 거부하고 해당 묶음을 다시 복사할 수 있게 한다.
- 번역 응답은 원본 VTT의 ID, 순서와 시간 코드를 유지해 렌더링한다. 완성된 VTT는 해당 회차에 저장한 뒤 플레이어에 바로 적용한다.

### 작업 이어하기와 정리

- 미완료 세션은 앱 userData의 subtitles/manual-translation-sessions에 회차 식별값과 원본 자막 SHA-256 지문으로 저장한다. 다른 회차나 다른 원본 자막에는 세션을 재사용하지 않는다.
- 기본값은 자동 정리 활성화와 즉시 정리다. 설정에서 즉시, 5분 뒤, 앱 종료 시점을 선택할 수 있다.
- 5분 정리는 main process 타이머로 수행하고, 앱을 다시 켠 경우 저장된 만료 시각을 확인해 타이머를 복구한다.
- 앱 종료 시점 정리는 완료된 세션만 지운다. 번역 실패·중단·미완료 작업은 보존한다.
- 저장된 한국어 VTT는 임시 세션 정리 대상이 아니다. 저장 위치 열기와 원본 자막 복구를 제공한다.
- 클립보드는 앱이 임의로 비우지 않는다.

Electron 통합은 격리된 임시 userData/sessionData/cache와 고유 AppUserModelId로 `app.asar`의 실제 main/preload/renderer를 숨김 BrowserWindow에서 실행하고, 실제 renderer DOM 버튼 이벤트를 전달했다. 최종 `npm run test:phase1-main` 종료 코드 0이며 합성 영어·일본어 자막 처리와 저장 결과를 검증했다. 물리 마우스나 Computer Use는 사용하지 않았다. v0.5.14 adapter renderer 검증은 upstream 원본 UI 전체 대신 제한된 합성 host DOM을 사용했다. 따라서 실제 v0.5.14 원본 index.html 전체 화면에서의 시각 검증은 미실시다.

패키징은 node_modules/electron-builder로 Windows --dir unpacked 폴더만 생성했다. NSIS 설치기를 만들거나 실행하지 않았고 실제 LilacAnime 설치본·사용자 프로필·업데이트 캐시를 열거나 수정하지 않았다. 테스트별 userData, sessionData, cache와 AppUserModelId는 별도 임시값을 사용했다.

통합 테스트 로그에는 잘못된 빈 클립보드 입력 및 재생 불가 회차를 거부하는 의도된 예외 로그가 있다. 최종 테스트 프로세스는 종료 코드 0이었다.

최초 직접 Electron 실행의 종료 정리에서 Chromium 언어 사전 파일 잠금(EBUSY)이 발생해 해당 실행이 만든 합성 userData/sessionData 임시 디렉터리 하나가 로컬 %TEMP%에 남았다. 후속 안전 래퍼 실행은 자체 임시 디렉터리를 정상 정리했다. 남은 디렉터리는 재귀 삭제가 자동 검토에서 차단되어 그대로 두었고, 사용자 프로필로 오인될 가능성을 없애기 위해 저장소 문서에는 절대 경로를 기록하지 않았다.

## 사용자 사용 흐름

1. 플레이어에서 영어 또는 일본어 자막 트랙을 선택한다.
2. ChatGPT 수동 번역 버튼을 누른다.
3. 요청 복사·ChatGPT 열기를 누른 뒤, 브라우저에 요청을 붙여넣어 직접 보낸다.
4. 응답 JSON을 앱 입력창에 붙여넣고 결과 확인을 누른다. 문장이 여러 묶음이면 같은 흐름을 반복한다.
5. 모든 ID가 확인되면 한국어 VTT가 자동 저장되고 현재 영상에 적용된다.
6. 실패한 응답은 오류 안내 후 다시 복사할 수 있다. 중단한 세션은 같은 회차와 원본 자막을 선택하면 이어갈 수 있다.
7. 번역 설정에서 앱 내부 임시 데이터 정리 시점과 저장 자막 위치를 관리한다. 원본 자막으로 돌아가기도 가능하다.

계정 연결 버튼은 실제 인증 기능이 아니며 현재 사용할 수 없다. 앱 내부 임시 정리도 ChatGPT 웹 대화 삭제를 수행하지 않는다.

## 미구현 및 한계

- 공식 SIWC 프로젝트 자격과 등록이 확인되지 않아 OAuth 로그인, ChatGPT 계정 상태 표시, 연결 해제는 동작하지 않는다.
- ChatGPT 플랜 사용을 포함한 자동 번역 요청, 실제 ChatGPT 응답, 계정 만료·사용량 제한 처리는 검증하지 않았다. 자동 요청을 완료했다고 간주하지 않는다.
- 실제 ChatGPT 웹 대화 열람·삭제는 지원되지 않는다. 앱은 사용자가 붙여넣은 번역 임시 응답만 관리한다.
- 자막 번역은 테스트용 합성 영어·일본어 문장으로 검증했다. 실제 작품 번역 품질과 외부 공급원 자막·영상의 일치는 미검증이다.
- 기존 로컬 AI 번역 코드는 수정하지 않았고 전체 테스트가 통과했지만 실제 로컬 모델 요청은 수행하지 않았다.
- Electron 통합 UI 버튼은 실제 renderer DOM 이벤트로 검증했다. 화면 캡처·고해상도 화면 배치와 실제 포인터 조작은 검증하지 않았다.
- 이 작업은 기존 실제 설치본에 적용하지 않았다. unpacked 폴더는 검증 산출물이며 일반 사용자용 설치본이나 공개 패키지가 아니다.
