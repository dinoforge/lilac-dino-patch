# LilacAnime 업데이트 후 패치 유지 — 1단계 검증 결과

2026-10-11 / 브랜치 `codex/persistent-patch-manager`
기준 `codex/integration-01-02`, 커밋 `4610a45f52e9a076b67a6774bcf3887dc390e485`
공식 원본 최신 릴리스 확인: v0.5.14

## 사용자 목표

기존 LilacAnime 설치본에 Patch 01·02를 한 번 적용한 다음, 공식 자동 업데이트가 완료되어도 앱 **내부에서** 기능이 유지되도록 한다. 별도 빌드나 오버레이를 계속 만들어 사용하는 것은 목표가 아니다.

## 구현된 것

- `patch-manager/core.cjs`: 버전·대상 파일 SHA-256·삽입 위치 검증 및 거부 판정
- `patch-manager/staging.cjs`: 새 임시 합성 프로젝트만 새 임시 사본으로 복제해, 그 복제본에 샘플 UI 슬롯을 삽입
- `patch-manager/cli.cjs`: `--help`, `--demo`만 수용, 실제 앱 관련 인수와 설치 패치 명령은 없음
- `patch-manager/test/manager.test.cjs`: 9개의 안전성 회귀 검사

`node --test patch-manager/test/manager.test.cjs`를 Node v22.16.0, 별도 격리 Linux 실행 환경에서 수행해 **9/9 통과**했으며 3개 JS/CJS 구문 검사도 통과했다. 이 검증은 공식 Windows LilacAnime 실행 결과가 아니다.

## 안전성 및 결론

- 샘플 원본 트리를 변경하지 않고 새 사본만 생성함
- 0.5.14 → 0.5.15 등 **미검증 버전에서 적용 중단**
- 기존 버전이라도 파일 해시가 다르면 중단
- 사용자가 기존에 사용 중인 설치본, 프로필, 업데이트 캐시는 접근/수정하지 않음
- 기존 중단된 Windows 감사와 미추적 파일, 공식 업데이터를 건드리지 않음
- 실제 코드 01·02의 자동 재적용, 실제 설치본 내부 UI 표시, 업데이트 후 지속성: **미구현/미검증**
