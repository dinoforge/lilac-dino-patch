## 구현

- Patch 02는 ChatGPT 웹 수동 번역 절차를 유지하고, 번역 저장 완료 후 바로 자막을 적용한다. 뒤이은 앱 내부 임시 세션 정리 오류가 저장 실패처럼 보이거나 중복 저장을 유발하지 않도록 했다. 웹 자동 입력, 응답 자동 수집, 대화 자동 삭제는 지원되지 않는 상태로 계속 비활성화했다.
- Patch 03은 RE:Anime, Miruro, Animenosub, 애니24(Ohli24), Linkkf의 초기 카탈로그 페이지와 제목 검색을 통합 화면에 모은다. 검색 결과는 확인 가능한 AniList/MAL ID를 우선으로 묶고, ID가 없으면 정규화 제목·연도·형식·시즌이 모두 일치할 때만 묶는다.
- 작품 상세는 연결된 공급원별 회차를 불러오고 각 회차에서 공급원 재생 선택지를 보여 준다. 회차 번호와 비어 있지 않은 정규화 제목이 정확히 일치할 때만 같은 줄에 묶는다. Linkkf의 서버별 재생 항목도 고를 수 있다. 호출 시간 제한 후 공급원 실패를 표시하고 응답한 공급원의 결과를 유지한다.
- Patch 01/02/03 토글은 독립적이다. 구형 두 키 설정은 기존 값을 보존하면서 Patch 03을 OFF로 읽고, 저장 시 세 키로 기록한다. Patch 03 OFF에는 통합 카탈로그 asset과 UI를 적용하지 않는다. 기능 플래그는 원본 Content Security Policy를 따르도록 로컬 외부 JS로 전달한다.

## 제한

Patch 03 검색·목록은 각 공급원 API가 반환하는 첫 페이지 결과를 사용하며, 페이지를 계속 넘기는 통합 탐색은 아직 없다. 실제 웹 공급원 검색, 영상 resolve/재생, 원본 설치본 GUI는 검증하지 않았다. 모의 Electron 통과는 실제 공급원 작동 증거가 아니다. 실제 ChatGPT 로그인/번역 및 ChatGPT 웹 대화 자동 삭제도 미구현이다.
