## CI 지출 최소화

저장소 루트에서 먼저 다음 명령을 실행합니다.

```bash
node scripts/dino-release-preflight.cjs
```

Rust 환경이 있다면 `--rust` 옵션을 추가합니다.
`build-dino-native-gui.yml`은 `workflow_dispatch`만 활성화하며,
가벼운 Node 검사가 통과한 경우에만 Windows 컴파일이 실행됩니다.
실제 Windows 실행 및 공식 LilacAnime 설치본 적용 테스트를 통과하기
전까지는 이 작업을 완료된 Beta 8 릴리스로 안내하지 않습니다.

## 사용자 데이터 보호 원칙

- 원본 LilacAnime 제목 캐시, 설정, 라이브러리, 다운로드는 수정하지 않습니다.
- SQLite 파일 `dino-work-index.sqlite`는 별도로 보관하고 v2→v3에 파괴적 마이그레이션을 사용하지 않습니다.
- 원본 ASAR/백업이 다르면 자동 덮어쓰지 않으며 검증된 기록만 수동 복구합니다.
- Preview ZIP에 공식 앱 실행 파일 또는 원본 ASAR를 넣지 않습니다.
