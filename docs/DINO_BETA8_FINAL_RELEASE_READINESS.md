# DinoPatch Beta 8: 통합 안정화·재현 절차 및 배포 준비

## 검증 범위

최종 빌드는 공식 LilacAnime 실행 파일이나 사용자 데이터를 포함하지 않는
**DinoPatch Windows GUI 미리보기**입니다. 개인 Windows 설치 경로 및 프로필은
CI 러너에서 접근할 수 없습니다. 버전 정보가 미등록이어도 고정된 버전/해시
허용 목록 없이 ASAR **구조 앵커**를 기준으로 패치 적용 가능성을 판단합니다.

## 검증 순서 (1~10)

1. 실제 Node 22 전체 패치 회귀 테스트와 5개 임베디드 모듈 해시 검사
2. Rust CLI 전체 테스트와 코딩 포맷 검사
3. `node:sqlite` DB 파일에서 수동 한국어 제목·연결/분리 저장 및 재시작 복원 테스트
4. 통합 UI 모의 테스트: 긴 제목, 반응형 진단 카드, 재검색 버튼, 키보드 접근성
5. Windows 러너 합성 ASAR에서 적용/해제·버전 업데이트·기존 백업 유지
6. 5개 공급원 다국어 검색 진단과 단일 공급원 재검색(검색 계약 모의 테스트)
7. 동일 작품/시즌/회차 확인, 대체 재생 주소 사전 검사와 원래 재생 위치 보호
8. SQLite 손상 시 DB 무변경/로컬 캐시 전환과 구체적인 비파괴 복구 안내
9. 진단/상태 보존 문서와 해시 영수증 정리
10. **상기 자동 게이트가 통과한 경우에만** Windows GUI 빌드·PE GUI 서브시스템
    검증·프로세스 시작 검사·ZIP 아티팩트 생성

## Windows 실사용 확인 목록

실제 `v0.5.65` 설치본이 있는 PC에서 LilacAnime를 종료하고 별도의
테스트 복사본 및 프로필을 사용하세요.

- 원본 `resources/app.asar`를 별도 위치에 백업하고 SHA-256을 기록합니다.
- DinoPatch 상태와 패치 대상 구조 검사 결과가 `UNPATCHED` / 호환으로 표시되는지 확인
- 패치 적용→통합 모드 검색→공급원 5개 진단→공급원별 재검색을 확인
- 한국어 제목 수정/공급원 수동 연결·분리를 저장 후 앱을 재시작해 유지 여부 확인
- 정규 3화/특별편/다른 시즌 3화가 뒤섞이지 않는지 확인
- 원래 재생 위치와 자막 설정이 전환 후 유지되는지 확인
- SQLite 안전 백업으로 생성된 파일과 SHA-256 확인
- 패치 해제 후 원본 ASAR 해시가 최초 기록과 일치하는지 확인
- 공식 앱이 업데이트되면 **버전 번호 등록 없이** 구조 앵커로 호환성을 재평가

사용자 실제 설치본과 스트리밍 서비스가 확인되기 전에는 특정 작품이
항상 `5/5` 연결 또는 항상 재생 가능하다고 주장하지 않습니다.

## SQLite 장애 복구 안내 (비파괴)

1. 문제가 발생하면 LilacAnime를 종료하고 DB에 대한 자동 복원을 시도하지 마세요.
2. 기존 `dino-work-index.sqlite`와 동명 `-wal`/`-shm` 파일이 있다면
   **함께** 별도 폴더에 복사합니다. 원본은 삭제하거나 바꾸지 않습니다.
3. `DinoPatchBackups`의 백업을 새 임시 폴더에 따로 복사하여
   `PRAGMA quick_check`, `PRAGMA foreign_key_check`로 무결성을 확인합니다.
4. 수동 제목, 연결/분리 기록과 최근 DB 변경분을 비교한 후에만 복구 방식을 선택합니다.
5. DinoPatch가 자동으로 원본 DB를 바꾸는 경로는 없으며, SQLite가 사용할 수 없을
   때 기존 로컬 캐시는 그대로 유지됩니다.

## CI 자원 정책

GitHub Actions는 수동 배포용 워크플로를 원형대로 유지합니다.
이 배포 후보용 별도 **1회성 검증 브랜치**에서 preflight가 통과해야만
Windows GUI 빌드가 실행되게 합니다. 이 검증이 실패한 경우 자동 재시도나
후속 CI를 실행하지 않습니다.

## 남은 실제 확인

CI 자동 검사는 실제 Windows v0.5.65 설치본의 UI 화면·5개 스트리밍
공급원의 특정 작품 재생 가능성을 보장하지 않습니다. 해당 검증 결과가
없으면 빌드 결과를 '실사용 최종 인증'이 아니라 **테스트용 미리보기**로 표기합니다.
