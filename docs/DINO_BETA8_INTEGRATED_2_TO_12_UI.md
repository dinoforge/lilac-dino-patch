# DinoPatch Beta 8 — 통합 모드 개선 2~12 + UI

## 범위
이 패치의 교차 공급원 기능과 진단 UI는 **통합 모드에서만** 활성화됩니다.
개별 공급원 모드에서는 공식 LilacAnime의 검색·상세·재생 호출을
그대로 사용하고, Dino SQLite 초기화도 시작하지 않습니다.
원본 `app.asar`, SQLite 원본 파일, 공식 제목 캐시, 사용자 저장 자료,
이전 버전 패치 백업을 삭제·교체하는 로직을 추가하지 않았습니다.

## 2. 통합/개별 모드 격리
- 검색·상세·재생 실패 시 다른 공급원 제안·진단 UI는 통합 모드로 제한
- 모드 변경 후 새로고침하여 별도 DB 연결도 통합 모드에서만 시작
- 수동 연결·제목 기록은 모드를 바꿔도 저장된 채로 유지

## 3. 공급원별 연결 원인
5개 공급원에 각각 연결 완료, 미검사, 검색 결과 없음, 관련 없는 작품,
검색 페이지 제한, 일부 응답 오류, 전체 응답 오류, 작품 확인 필요를 표시.
검색 호출 수·검색 결과 수·사용된 검색어를 확인할 수 있습니다.
동일한 이름의 후보가 연결 거절된 경우 ID/연도/시즌/작품 형식 불일치도 표시합니다.
**검색 결과가 여러 개여도 동일 작품이라고 확정하지 않습니다.**

## 4. 공급원별 재검색
각 미연결 공급원 카드의 `이 공급원 재검색`을 눌러 **해당 공급원만**
검색합니다. 해당 공급원의 오래된 요청 캐시만 무효화하고 다른 공급원은
다시 요청하지 않습니다. 기존 전체 재검색 버튼은 유지합니다.
단일 공급원 검사 결과를 근거로 5개 전부를 '없음'으로 기록하지 않습니다.

## 5. 동일 작품 검색 안전성
한국어·영어·일본어 별칭 검색과 원본 앱 제목 확인을 유지합니다.
비슷한 이름은 추천 후보일 뿐이며, 방영 연도·시즌·ID·형식 조건이
일치해야 자동 연결됩니다. 다른 시즌이나 수동으로 분리한 연결은
무조건 유지합니다.

## 6. 회차 구분
0화, OVA·OAD, 예고·PV, 총집편, 극장판, 특별편은 일반 회차 숫자와
분리합니다. 같은 번호의 후보가 둘 이상이거나 시즌/파트 정보가
충돌하면 교차 공급원 자동 재생 전환을 중단합니다.

## 7. 재생 실패 보호
기존 공식 플레이어의 HLS 복구 시도를 우선하고, 실패 시 사용자가
`다른 공급원에서 이 회차 재생`을 누른 경우에만 후보를 조회합니다.
현재 작품·회차·시즌을 재검증하고 가능한 경우 대체 영상 주소를
확인한 후 전환합니다. 후보가 없거나 조회가 실패하면 기존 컨텍스트와
시청 위치를 유지합니다. **전환 후 발생할 수 있는 모든 네트워크 장애까지
복구된다고 보장하지는 않습니다.**

## 8. 안전한 SQLite 백업
`공급원·DB 상태`에서 `SQLite 안전 백업`을 누르면, 미저장 편집
내역을 DB에 기록한 다음 `PRAGMA quick_check`와 외래키 검사를 거쳐
SQLite `VACUUM INTO`로 새로운 **읽기 일관성을 갖춘 별도 파일**을 만듭니다.

- 저장 위치: LilacAnime userData 내부 `DinoPatchBackups/`
- 파일명: `dino-work-index-<UTC timestamp>-<random>.sqlite`
- 원본 DB, 기존 백업, WAL, 사용자 기록은 덮어쓰지 않음
- 생성 후 새 파일을 읽기 전용으로 열어 `quick_check`와 작품 수 확인
- 무결성 확인에 실패하면 백업 성공으로 표시하지 않음
- **자동 원본 복원은 구현하지 않음:** 복원은 사람이 검토한 별도 절차로 처리

## 9. 검색 속도
기존 동시성 상한, 재검색 캐시, 공급원별 페이지 수 제한을 유지합니다.
통합 화면의 원격 검색에는 페이지별 12초, 백그라운드 검색에는 9초
응답 대기 상한을 둡니다. 상한이 지난 요청은 실패로 진단하되 이미
확인된 작품 연결·제목을 삭제하지 않습니다. 서버 측 요청 취소를
보장하는 기능은 아닙니다.

## 10. UI
- 공급원 5개를 반응형 진단 카드로 표시
- 연결 상태, 원인, 검색어, 후보 수, 해당 공급원만 재검색하는 버튼 제공
- 좁은 화면은 2열 또는 1열로 재배치하고 키보드 포커스 표시
- 개별 공급원 모드에서는 이 UI를 표시하지 않음
- 기존 재생 공급원 가로 탭·작품 제목 수정 UI는 유지

## 11. 진단 JSON 저장
`공급원·DB 상태`에서 `진단 JSON 저장`을 누르면 공급원별 상태·
후보 수·요청 횟수·거절 사유·DB 건강 상태·회차 확인 통계를
저장합니다. 작품 제목, 검색어, 영상 URL, 설치 경로, 작품 ID,
개인 설정은 내보내지 않습니다. 실패 시 성공 메시지를 표시하지 않습니다.

## 12. 패치 안전성과 검증
기존 버전 번호 비의존 구조 검증, 원본 ASAR 해시 확인, 버전별 백업,
패치 취소/복원 및 pending 복구 기록 동작은 변경하지 않았습니다.
변경한 내장 JavaScript/CSS 모듈의 SHA-256 매니페스트를 갱신하며
Windows GUI 빌드 없이 아래 로컬 검증 게이트를 실행할 수 있습니다.

```powershell
node scripts/dino-release-preflight.cjs
node scripts/dino-release-preflight.cjs --rust
```

### 검증 상태
- 공급원별 재검색이 5개를 다시 요청하지 않는지 모의 상세 화면 검증
- 다국어 검색, 동일 작품 식별 거절 사유, 통합/개별 UI 격리 검증
- SQLite 손상 시 비파괴 로컬 캐시 전환과 백업 전 안전 검사 검증
- Node SQLite WAL + `VACUUM INTO` 독립 파일 생성/무결성 검사 실험
- 기존 버전별 패치 안전성 계약은 그대로 유지

전체 저장소 로컬 게이트와 실제 LilacAnime 설치본의 통합 기능·Windows
ASAR 패치 적용/원복은 별도 검증이 필요합니다. 이 수정 브랜치의
**GitHub Actions CI 및 새 Windows EXE 빌드는 실행하지 않았습니다.**
