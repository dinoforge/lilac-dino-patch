# DinoPatch Beta 8 · 통합 모드 전용 개선 1~6

## 적용 범위
- **통합 검색/통합 상세 보기에서만** 아래 진단, 교차 공급원 검색과 재생 전환을 활성화합니다.
- 개별 공급원 모드는 기존 LilacAnime 검색, 상세, 재생 흐름을 그대로 호출합니다.
- SQLite 작품 인덱스 초기화도 통합 모드에서만 시작합니다. 통합 모드로
  바꿀 때는 기존 설정 저장 후 앱을 새로고침해 인덱스가 시작됩니다.
- 공식 앱의 기본 제목 캐시, 선호 설정, 사용자 다운로드 및 시청 기록,
  DinoPatch 이전 패치 백업은 삭제하거나 재설정하지 않습니다.

## 1. 공급원 5개 연결 진단
통합 작품 상세 화면에서 공급원별로 다음 상태를 구분합니다.
`연결 완료`, `작품 확인 필요`, `검색 결과 없음`,
`다른 작품만 검색됨`, `검색 페이지 제한`, `일부 응답 오류`,
`응답 오류`, `아직 검사하지 않음`.

검색 결과가 여러 개여도 **동일 작품의 식별 확인을 거쳐야**
연결 수에 포함합니다. 확인이 끝나지 않은 공급원을 임의로
`5/5`에 넣지 않습니다. 한 번 검사한 진단 결과는 같은 작품의
다른 연결 공급원으로 진입해도 표시할 수 있게 재사용합니다.

## 2. 한국어·영어·일본어 검색 정확도
기존 언어별 별칭 우선순위와 원본 공급원 검색 API를 사용하며,
부분적인 검색 오류가 있으면서 결과가 0개인 공급원도
제한된 별칭 재검색 대상에 포함합니다.
수동 재검색은 기존 비동기 검색 캐시를 우회합니다.
검색어/페이지 상한은 유지하여 불필요한 호출을 늘리지 않습니다.

## 3. 회차 번호 정확도
정규 회차 비교에서 0화, 특별편, 예고편(PV/Trailer/Preview),
OVA/OAD, 총집편과 극장판을 제외합니다.
정규 회차에서는 번호와 더빙 구분뿐 아니라 시즌·파트·분할
쿨 표기가 있는 경우 **양쪽이 동일하다는 근거가 있을 때에만**
교차 공급원 후보로 인정합니다.
같은 번호의 편집본이 둘 이상 존재하면 자동 선택하지 않습니다.

## 4. 재생 실패 보호
재생 공급원 전환은 통합 모드에서 기존 재생 실패가 표시되고
사용자가 전환을 선택한 경우에만 시도합니다.
후보 재생 주소를 먼저 확인하고 기존 작품·회차·시즌 컨텍스트가
유지되는 경우에만 전환합니다.
후보가 없거나 주소 확인에 실패하면 기존 재생 화면, 회차와
재생 위치를 건드리지 않습니다.
실제 스트리밍 도중의 모든 오류가 해결되는 것은 아니므로
공식 플레이어의 서버 재시도/복구 로직은 보존합니다.

## 5. SQLite 무결성·비파괴 복구
기존 `dino-work-index.sqlite`에 대해 진단성 `quick_check(1)`와
외래키 검사부터 수행한 다음에만 WAL 설정이나 기존 스키마
마이그레이션을 진행합니다.

검사 실패 시:
- **손상되었다고 판단한 DB를 삭제하거나 덮어쓰거나 재구성하지 않습니다.**
- SQLite 쓰기를 막고 기존 로컬 `workIndex.v1` 캐시로 자동 전환합니다.
- 캐시에 저장된 수동 한국어 제목·공급원 연결은 그대로 사용합니다.
- 원본 DB를 정상 복구했다고 표시하지 않습니다. 기존 DB의 수동
  복원에는 별도 백업과 사용자의 검토가 필요합니다.
- 앱 재시작 시 SQLite 검사를 다시 수행합니다.

## 6. 통합 검증 및 배포 조건
테스트는 다음을 포함합니다.
1. 5개 공급원의 진단 원인 분류와 통합/개별 모드 분리
2. 오류가 일부 발생한 검색에서 제한된 다국어 재검색
3. 0화·특별편·동일 화수 중복·시즌/파트 충돌 차단
4. 대체 스트림 실패 시 원래 재생 컨텍스트 유지
5. SQLite quick_check/외래키 오류 발견 시 DB 미변경, 로컬 캐시 전환
6. 기존 제목/수동 연결·해제/백업 보존 계약

저장소를 로컬에 체크아웃한 뒤 아래 명령으로 **GitHub Actions 없이**
전체 Node 회귀 테스트와 내장 모듈 SHA-256 검증을 실행합니다.

```powershell
node scripts/dino-release-preflight.cjs
```

원하면 별도로 Linux/Windows 개발 환경에서 Rust CLI 테스트도 수행할
수 있습니다(Windows GUI EXE를 빌드하는 명령은 아님).

```powershell
node scripts/dino-release-preflight.cjs --rust
```

**실제 사용자 설치본이나 SQLite 파일에 대한 적용·복원 테스트는
이 소스 수정 단계에서 수행하지 않았습니다.** 통합 모드의 검색
응답은 공급원별 실제 작품 보유·서비스 상태에 따라 달라집니다.
CI를 실행하지 않았으며 새 Windows EXE는 만들지 않았습니다.
