# DinoPatch Beta 8 · 통합 UI 마무리 및 테스트 점검

## 범위

이번 단계는 통합 모드 전용 상세 화면 UI와 안전성 회귀 검사입니다.
기존 개별 공급원 검색·상세·재생 로직과 Rust 패치 적용·원복 처리,
SQLite 원본 데이터, 사용자 수동 제목·연결 기록은 수정하지 않습니다.

## UI 조정

- 통합 상세 화면은 `detail-source-picker dino-integrated-picker` 전용 클래스를
  사용합니다. 새 섹션 바깥의 공식 개별 공급원 피커를 변경하지 않습니다.
- 긴 한국어·영어·일본어 작품 제목은 잘라서 생략하지 않고 자동 줄바꿈합니다.
  공백 없는 긴 영어 제목도 `overflow-wrap:anywhere`로 표시합니다.
- 작은 창에서는 제목과 공급원·DB 관리 버튼을 별도 줄로 배치하고,
  버튼이 겹치지 않도록 너비·간격·정렬을 조정했습니다.
- 재생 공급원 선택 버튼은 **기존 1줄 가로 스크롤 레일**을 유지합니다.
  길어진 공급원 상태 문구가 잘려 보이지 않도록 줄바꿈을 허용합니다.
- 공급원별 진단 카드의 여백을 정리하고, 작은 창에서는 2열,
  폭 380px 이하에서는 1열로 표시합니다.
- 재검색, SQLite 안전 백업, 진단 JSON 저장 버튼은 줄바꿈·
  키보드 포커스·대기 중 사용 불가 상태를 유지합니다.
- 중복 선언된 진단 카드 CSS 규칙을 정리하고, 반응형 규칙의
  스코프가 공식 개별 공급원 화면에 번지지 않도록 했습니다.

## 테스트 점검

최신 GitHub 소스 및 수정 파일을 읽어 JavaScript 실행 환경의
메모리 모의 파일시스템·화면 요소를 사용한 회귀 테스트를 수행했습니다.

- 통합 검색 모델: **36/36 통과**
- 통합 상세·재생·UI: **67/67 통과**
- 공식 개별 공급원 설정 보존: **15/15 통과**
- 회차 비교: **2/2 통과**
- Rust/Windows 패치 소스의 안전성 계약 정적 검사: **17/17 통과**
- 위 범위 합계 **137/137 통과**
- 변경된 `src/integrated-search.css`와 `patch03-bridge.js`의
  SHA-256을 기존 매니페스트와 대조한 뒤 새 해시를 기록했습니다.

이 검증은 **실제 Node.js 전체 테스트 실행과 동일하지 않습니다.**
GitHub 연결에서는 저장소 소스를 조회할 수 있지만 이번 실행 환경에
전체 저장소가 로컬 체크아웃되어 있지 않습니다. 실제 Node SQLite
실파일 통합 테스트, Rust CLI 테스트, Windows ASAR 적용·해제 및
LilacAnime 실사용 화면 검증은 아직 완료되지 않았습니다.
이를 통과한 것으로 표시하지 않습니다.

## 실제 저장소에서 마저 실행할 로컬 게이트

저장소가 체크아웃된 Windows/Linux 개발 환경에서 다음을 실행합니다.

```powershell
node scripts/dino-release-preflight.cjs
node scripts/dino-release-preflight.cjs --rust
```

추가로 Windows 테스트 설치 **복사본**에 패치 적용·해제,
SQLite 백업 및 다국어 검색/재생 흐름을 확인해야 합니다.

이번 수정은 **GitHub Actions CI 실행 0회**, **Windows EXE 빌드 0회**입니다.
