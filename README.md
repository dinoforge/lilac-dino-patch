# 라일락 디노 패치

**Lilac Dino Patch** · Windows x64 · 비공개 개발 프로젝트

저장소: [github.com/dinoforge/lilac-dino-patch](https://github.com/dinoforge/lilac-dino-patch)

공식 원본: [LilacAnime Desktop](https://github.com/whispelyn-byte/LilacAnime-desktop) · [업스트림 연결 안내](docs/UPSTREAM_LINK.md) · [디노 베타 릴리즈 설명 초안](docs/releases/dino-v0.1.0-beta.1.md) (**아직 릴리즈 게시 전**)

라일락 디노 패치는 공식 LilacAnime Desktop **소스 폴더**의 파일 구조와 호출 계약을 검사하고, 호환되는 소스에 디노 패치를 적용·관리하는 Electron 기반 Windows 관리자입니다. 공식 애플리케이션을 대체하지 않으며, 작품 상세·회차·공급원 resolve·영상 재생은 공식 LilacAnime 흐름을 사용합니다.

> 이 프로젝트는 공식 LilacAnime와 제휴하거나 공식 배포하는 제품이 아닙니다. 코드·에셋·외부 콘텐츠의 이용 권리와 배포 범위가 확인되지 않아 저장소는 비공개이고 공개 다운로드 및 GitHub Release는 제공하지 않습니다.

## 주요 기능

- 공식 버전 문자열만 보지 않고 소스 구조, 패치 연결 지점과 호출 계약으로 호환성을 판단합니다.
- 검사가 통과하면 패치 대상 파일을 백업한 뒤 자동 적용하고, 이미 적용된 경우 중복 변경을 피합니다.
- 공식 소스의 변경을 감지하고 다시 검사해 호환되는 경우에만 패치를 재적용합니다.
- 여러 공급원의 검색 결과를 통합하고, 근거가 있는 동일 작품을 묶어 작품별 공급원을 선택·전환합니다.
- 공식 상세 창, 회차 선택, `provider:resolve`, 원본 플레이어와 자막 흐름에 연결합니다.
- 기존 LilacAnime 7요일 주간표와 공식 앱 기능을 유지합니다.
- 충돌이 없는 패치 전용 백업·해제·복원, 작업 이력과 진단을 제공합니다.
- 공식 테마를 읽기 전용으로 연동하고 읽기 실패 시 시스템 테마로 대체합니다.

## 검증 기록

아래는 **2026-11-03에 기록된 A35-final 검증 결과**입니다. 이번 저장소 이름·문서 변경에서 테스트를 다시 실행한 결과가 아닙니다.

- 관리자: A35-final Windows x64
- 공식 대상: LilacAnime Desktop v0.5.58, 커밋 [`e2a28266b0ee9c9391bdf41801e39fd5342c7b3c`](https://github.com/whispelyn-byte/LilacAnime-desktop/commit/e2a28266b0ee9c9391bdf41801e39fd5342c7b3c), Git tree `638476606f3d4a2712c5cfbe4c1013cbcb78c14e`
- 자동화: 전체 `npm test` 1,010/1,010 통과, Python 관리자 63/63, Node UI 21/21, 공식 호출 계약 10/10
- 격리 Electron 실행에서 통합 검색, 공급원 전환, 공식 상세·회차, Miruro 원본 플레이어의 영상 프레임·재생 시간 진행·자막을 확인했습니다.
- 패치 해제 후 공식 소스 170개 파일이 원본과 일치하고 패치 모듈이 남지 않는 것을 확인했습니다.

이 검증은 v0.5.58과 해당 테스트 시점의 외부 서비스 응답에 대한 결과입니다. 모든 공식 버전이나 모든 공급원의 지속적인 가용성을 보장하지 않습니다.

## 설치와 사용

공식 LilacAnime **설치 프로그램만으로는 패치 대상 소스 폴더가 제공되지 않습니다.** `src`, `electron`, `package.json`이 함께 있는 공식 소스 루트가 필요합니다.

GitHub 공개 다운로드는 권리 확인 전까지 제공하지 않습니다. 이미 별도로 전달받은 검증된 A35 Windows ZIP을 사용할 권한과 사본이 있는 경우:

1. 실행 중인 LilacAnime를 종료합니다.
2. ZIP을 풀어 안의 `DinoPatchManager` 폴더 전체를 공식 소스 루트에 복사합니다.
3. 폴더와 `디노패치관리자.exe` 파일 이름을 바꾸지 않고 실행합니다.
4. 관리자는 소스 구조와 패치 상태를 확인하고, 호환될 때만 백업 후 자동 적용합니다.

관리자 배포본에는 실행에 필요한 런타임이 포함되어 있어 별도의 Python 설치를 요구하지 않습니다. 배포 ZIP의 공식 다운로드 링크는 현재 없습니다. A35 ZIP은 개발자의 로컬 배포 폴더에 보존되어 있으며 이 저장소의 GitHub Release에는 업로드되지 않았습니다.

## 패치 해제와 복원

- **디노 패치 해제**는 관리자가 소유한 변경만 제거합니다.
- **백업 복원**은 선택한 적용 시점의 파일 지문과 현재 파일 상태를 확인한 뒤 해당 백업을 복원합니다.
- 사용자 파일과 예상하지 못한 수정이 발견되면 덮어쓰지 않고 중단합니다.
- 이 기능은 사용자 AppData, 시청 기록, 설정 전체 또는 설치된 LilacAnime를 복원하는 기능이 아닙니다.

## 호환성 및 업데이트 범위

v0.5.58은 실제 격리 앱 실행까지 기록된 검증 기준입니다. 새 공식 버전은 구조와 호출 계약을 다시 검사하며, 단순히 버전 번호가 새롭거나 비슷하다는 이유로 적용하지 않습니다. 구조 검사가 통과한 새 버전도 실제 검색·재생 검증과 동일하다고 볼 수 없습니다.

관리자는 공식 최신 릴리스 **조회**를 제공하지만, 공식 소스 다운로드·교체나 Windows NSIS 설치 업데이트는 제공하지 않습니다. 공식 업데이트 뒤의 자동 설치를 지원하는 것처럼 표시하지 않습니다.

외부 공급원은 응답 지연, 지역·접근 제한, 결과 없음 또는 서비스 구조 변경이 있을 수 있습니다. 한 공급원의 실패가 다른 공급원의 검색을 막지 않도록 설계하지만, 공급원 가용성을 보장하지 않습니다.

## 현재 저장소 이관 상태

저장소의 기본 브랜치 `main`에는 이전 LilacAnime Player의 실행 자료가 남아 있습니다. 별도 개발/검토 브랜치에는 A35 관리자 소스 이관, 독립 빌드 경로 및 관리자 수명주기·설정 호환성 개선(A/B 커밋)이 반영되어 있습니다. **기존 A35-final 배포 바이너리와 새 A/B 소스 산출물이 바이트 동일하다고 주장하지 않습니다.** 수동 재적용 GUI 실험 코드는 검토 브랜치의 A/B 커밋에 포함되지 않으며 전체 기능적 융합은 PARTIAL입니다. 기존 원본 앱 코드를 일괄 삭제·이동하거나 Git 이력을 병합하지 않았습니다.

이 저장소의 루트 `package.json`과 `.github/workflows/build.yml`은 기존 LilacAnime 앱의 Windows/macOS 빌드 구성입니다. 이 워크플로는 A35 관리자를 빌드하지 않습니다. A35 바이너리 ZIP은 일반 Git 커밋에 포함하지 않았습니다.

## 권리와 공개 배포 정책

저장소는 비공개 상태를 유지합니다. 코드·에셋·API·콘텐츠 이용 권리와 배포 범위를 확인하기 전에는 Actions 변수 `LILAC_RELEASE_RIGHTS_APPROVED`를 설정하거나 태그를 만들지 않습니다. 공개 Release, 설치 파일, 다운로드 링크를 임의로 만들지 않습니다.

공식 출처: [LilacAnime Desktop 저장소](https://github.com/whispelyn-byte/LilacAnime-desktop). 디노 패치는 독립적인 비공식 관리자입니다.
